# TermDeck v2.0.0

TermDeck 是一个 Windows 上的 SSH / SFTP 终端客户端：可拖拽、可停靠的终端窗格，加上会话树、
主机批量管理、端口转发、对象存储与 REST 工具页。**2.0 是一个里程碑版本** —— 它把
v1.6.0（上一个发布页）以来的九个版本汇总成一次发布，功能上等同于 v1.13.3。

如果你在用 1.6.0 或更早，这一页就是你错过的东西。

## 下载

| 文件 | 说明 |
| --- | --- |
| **`TermDeck-Setup-2.0.0.exe`** | 安装版（NSIS）：装到本机、带开始菜单与桌面快捷方式 |
| **`TermDeck-2.0.0-win-x64-portable.zip`** | 解压即用：解开双击 `TermDeck.exe` 就能跑，建议用这个 |
| `TermDeck-2.0.0-x64.exe` | 单文件便携版：一个 exe，首次运行自解压 |
| `SHA256SUMS-2.0.0.txt` | 上面三个文件的 SHA-256，下载后可核对 |

**首次运行会被 SmartScreen 拦一下**：安装包没有代码签名证书，Windows 无法确认发布者，
点「更多信息 → 仍要运行」即可。需要 Windows 10/11（本地 shell 依赖 ConPTY）。

## 从 v1.6.0 到现在

### 终端与重连

- **断线重连全程后台进行**（v1.11.1）：不再抢走你正在用的窗格、不再弹全局报错；失败原因写在
  该窗格自己的遮罩上。保留同一个 session id，**历史输出还在**，窗格尺寸也跟着变回来。
- **修掉「vim 只占半屏」的真因**（v1.11.1）：重连时按会话创建时的 80×24 建新 PTY，而渲染端
  「尺寸没变就不发 resize」，于是没人纠正它 —— 现在重连后的尺寸跟窗格一致。
- **`Ctrl+W` 交还给 shell**（v1.13.0）：它是 readline 的「删掉前一个词」，以前被绑在
  「关闭当前会话」上、按键根本到不了终端。现在默认不绑定（想用的人可以在快捷键里自己设），
  旧机器上存着的旧默认值会自动迁移掉，你自己改过的原样保留。
- **结束/重连的遮罩可以直接关掉**（v1.13.0）：「关闭窗格」按钮先停掉重试再关，
  **关掉之后不会再偷偷重连回来**。
- **重连页面的 `Ctrl+R`**（v1.6.1）：从布局恢复、尚未连接的窗格按它不再去找一个不存在的会话。
- **命令历史补全**（v1.3.0 起延续）：所有会话共用一份历史，前缀弹出、`↑↓` 选择，
  回车只把它填进命令行、不执行。

### 输出高亮（v1.12.0，并在 v1.13.1–1.13.3 连续修好可见性）

把输出里的**地址 / 链接 / 邮箱 / MAC / 文件路径 / 错误 / 警告 / 成功关键字**上色，
**4 套配色**（经典 / XShell 色块 / 柔和 / 单色），8 条规则可逐条开关。

- **只改显示**：文本本身、复制出去的内容、保存的输出，与远端发出的一模一样（实现是给单元格
  上色，不往缓冲区里注入转义序列）。
- 总开关、配色方案、规则现在是**一块**，选方案或勾规则会**自动打开**总开关；
  改动没保存时底部会明说「有未保存的更改」。

### 主机与会话管理

- **主机页分组折叠**（v1.9.0）：分组头一个 ▸/▾；折叠态会记住；搜索时自动展开
  （否则「筛出来却看不见」读起来像主机没了）。
- **勾选批量操作**（v1.11.0）：每台主机前的勾选框 + 页头「全选」，批量**删除 / 复制 / 移动到分组**。
  「全选」只选**屏幕上看得见**的那些，勾选是临时状态、做完就清空。
- **抽屉会话树一键折叠/展开所有分组**（v1.10.0）：批量折叠在主进程一次写完（一次写盘、一次广播）。

### 工具页

- **REST 页面**（v1.7.0）：页面自己不再被长正文拉长（两列 + 请求行限高）；请求头可以直接粘
  JSON（对象或每行 `Name: value`，写错明确报错且不动已有头）；**调用历史**每次发送都记
  （上限 60 条，可存下 / 改名 / 覆盖 / 删除）。
- **REST 页面整页中文**（v1.8.0）：48 条文案补齐，包括模板名和四类失败原因。

### 文件传输与界面

- **SFTP 下载速度**（v1.6.0）：根因是每次只发一个读请求（速度 = 块大小 ÷ 往返），
  改成固定并发 128K×16；同时支持**拖拽上传**（`webUtils.getPathForFile` 与 `text/uri-list`）。
- **传输进度条**（v1.5.x 起延续）：快捷指令栏上方自动出现一条横条，收起也读得出
  文件名 / 方向 / 百分比 / 速度，⌄ 展开是完整列表。
- **标签文字对比度**（v1.5.2）：修 dockview 主题变量被内层重新声明导致的覆盖失效，
  激活标签另加一条 accent 下划线作为**非颜色**线索。
- **一键排列所有窗格**（v1.3.x 起延续）：瓷砖 / 竖分割 / 横分割，可只排勾选的子集，
  排完自动等分。

## 校验

```powershell
Get-FileHash -Algorithm SHA256 .\TermDeck-Setup-2.0.0.exe
```

和附件里的 `SHA256SUMS-2.0.0.txt` 对一下即可。

- `~/.ssh/config` 导入**还没做**（README 的状态表里标着 ⬜）。
- 只提供 Windows x64 构建。
