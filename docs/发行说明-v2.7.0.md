# TermDeck v2.7.0

TermDeck 是一个 SSH / SFTP 终端客户端：可拖拽、可停靠的终端窗格，加上会话树、主机批量管理、
端口转发、对象存储与 REST 工具页。Windows 与 macOS 都有构建。

**这一版加两个一用就能感受到的改进**：

1. **终端窗格里可以 `Ctrl+F` 找文字了**（macOS 上是 `Cmd+F`）——找的是**整段历史输出**，不只屏幕上那几行；
2. **SFTP 列表可以右键了**，而且**下载按钮搬到了工具栏** —— 以前它单独藏在列表下面，列表一长就得先选中
   文件、再往下翻着找按钮。

> Windows 用户从 **v2.6.3** 升级上来即可；macOS 用户注意 **v2.6.1 的产物是坏的**，请用 v2.6.2 / v2.6.3 / 这一版。

## 新增

### 1. 在终端窗格里搜文字：`Ctrl`+`F`（macOS `Cmd`+`F`）

在任意窗格里按下去，右下角出现一个小搜索框：

- 找的是**这一整个会话缓冲**，不只屏幕上那几行 —— 往上滚很远才能看到的输出也找得到；
- **大小写不敏感**，命中高亮并显示计数（例如 `3 / 27`），当前那一条颜色更亮；
- `Enter` 跳下一个、`Shift`+`Enter` 跳上一个，到头会**自动回绕**；
- `Esc` 关掉搜索框，**焦点还给终端**，可以直接接着敲命令；
- 远端一直在刷输出也不会卡：重扫是节流的；
- **只找不改**：不会动你的选择、也不会碰剪贴板（这个终端是"选中即复制"，所以搜索走的是高亮图层）。

这个键位不进设置列表 —— 它就地在窗格里开框，不经过应用的快捷键系统；其余快捷键照旧都能在
**设置 → 快捷键** 里改。

### 2. SFTP 列表的右键菜单 + 下载按钮归位

**右键列表里的任意一行**，菜单里是：

| 菜单项 | 说明 |
| --- | --- |
| 打开 / 下载 | 目录给"打开"，文件给"下载" |
| 上传到当前文件夹 | 就等于把文件放进现在这个目录 |
| 刷新 | 重新读一遍当前目录 |
| 复制名称 · 复制路径 · 复制目录路径 | 文件名 / 完整远端路径 / 它所在的那个目录 |
| 复制名称到终端 · 复制路径到终端 | 把文字**打到提示符上**（不执行）—— 远端敲命令时不用再手打路径 |
| 属性 | 名称、类型、大小、修改时间、完整路径，显示在列表下方 |

在列表的**空白处**右键，拿到的是**当前目录自己**的那一份：刷新、上传到当前文件夹、复制目录路径、
复制路径到终端。

**下载按钮**现在紧挨 `⟳` 刷新与 `⭱` 上传，就在工具栏上；没有选中文件时它是**禁用**态，而不是消失。

## 已知边界（写在明处）

- **macOS 包仍未正式签名**：没有 Apple 开发者账号，首次打开要右键「打开」或 `xattr` 放行。
- **v2.6.1 的 mac 产物是坏的**（签名无效，双击报「已损坏」），请改用这一版或 v2.6.2 / v2.6.3。
- **若服务器拒绝 SFTP 子系统**（界面报 `Unable to start subsystem: sftp`）：这是服务器 / 网络路径
  那边的策略问题，不是客户端 —— 同一个账号换成复用已有连接的终端（WindTerm / MobaXterm / Xshell）
  能列目录，而在这台机器上用系统 OpenSSH 直接连同样会被拒。可以找管理员看 `sshd_config` 的
  `Match` / `ChrootDirectory` / `Subsystem` 有没有按来源地址命中规则。
- S3 页与端口转发页仍是英文界面。
- 只有 Windows x64 与 macOS 两个架构；没有 Linux 官方产物。

## 校验

```powershell
Get-FileHash -Algorithm SHA256 .\TermDeck-Setup-2.7.0.exe
```

```bash
shasum -a 256 TermDeck-2.7.0-arm64.dmg
```

和附件里对应的 `SHA256SUMS-*.txt` 对一下即可。
