# TermDeck v1.3.2

## 修复

**输入提示：点一下就消失**

补全提示以前只有 `Esc` 能关，鼠标点到别处它还在那儿挂着。现在在**任何地方按下鼠标**（别的窗格、抽屉、设置、
页面空白处）它立刻收起；点在提示列表自己身上不算关闭 —— 那一击是选中。`Esc` 照旧。

**拖拽分屏比例：拖到哪就停在哪**

以前拖分隔条时，比例会自己"跳"回平均分：拖的过程中一格一格地闪，松手后直接弹回 1:1，等于没法自定义比例。

原因是那个每 100ms 跑一次、用来防止窗格塌成 65px 的**布局看门狗**。它每次都直接调
`dock.layout(w, h, true)`，而这个调用**不只是量尺寸，它会重新分配整张网格** —— 于是拖到一半就被按回平均分。

现在看门狗先问一句"网格和容器已经一致了吗"（`Gridview.layout()` 会把量到的尺寸写成 `.dv-grid-view` 的
内联样式，所以这个判断可以直接从 DOM 读到）：一致就什么都不做 —— 这本来就是绝大多数时候的状态；同时在
**拖拽手势进行中绝不插手**。看门狗防的那个故障（网格卡在挂载时的 100×100 占位尺寸）读出来就是"不一致"，
照样会被修正。

## 验证

完整闸门 `npm run verify`：41 套件全过。

- `smoke:gesture` 21 → 24 条：新增用**真实鼠标事件**（CDP）拖分隔条的检查 —— 分隔条从第一步就跟着指针走、
  松手后落在释放的位置、1.2 秒后仍然是那个比例而不是弹回平均分。渲染层内的断言看不到这个问题，所以这条
  必须从外面驱动。
- `smoke:suggest` 29 → 31 条：点列表外面会关、点列表本身不会关。
