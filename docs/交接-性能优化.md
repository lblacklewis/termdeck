### 4b. 未用导出/局部变量

`tsc --noUnusedLocals --noUnusedParameters`（临时加进 tsconfig 跑一次，别提交）。历史上为消变量警告留下的 `void x` 一并清掉。

扫描脚本（**注意**：`Select-String` 没有 `-Recurse`，要用 `Get-ChildItem -Recurse | Select-String`；匹配模块名时用**裸名**，因为 import 写的是 `'./components/Foo'` 这种路径）：

```powershell
$all = Get-ChildItem src -Recurse -Include *.ts,*.tsx
foreach ($f in $all) {
  $n = [IO.Path]::GetFileNameWithoutExtension($f.Name)
  if ($n -in @('App','main','types','preload','env.d')) { continue }
  $hits = $all | Where-Object { $_.FullName -ne $f.FullName } | Select-String -Pattern $n -SimpleMatch
  if (-not $hits) { "ORPHAN: $($f.FullName.Replace($PWD.Path + '\',''))" }
}
```

### 5. 内存泄漏复查（三处）

1. **广播注册表**：`src/renderer/src/components/broadcast.ts` 的 `registerSink` / `registerTerminal` 在 pane 关闭时是否都摘掉了（`useTerminal` 的 dispose 里有 `unregisterTerminal`/`unregisterSink`，但要确认**广播模式开着**时关闭窗格也走这条路）；
2. **事件订阅**：`history:changed`、`settings:changed` 之类的广播订阅，组件卸载时是否 `off`；
3. **排列的 rAF**：`tile.ts` 的 `equalise` 里双 `requestAnimationFrame`，在窗格被快速关闭时可能碰到已销毁的 group —— 加一个 `if (!group.api)` 之类的前置判断（dockview 的 group api 在销毁后调用会抛）。
