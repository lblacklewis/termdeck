# TermDeck v1.5.0

## 新增

**文件上传/下载有了自己的窗口，进度都在里面**

以前传文件只能在 SFTP 面板里等：面板只报它当前看着的那个会话，而且**离开面板就什么都看不到了**。现在有一个
独立的传输窗口。

- 打开方式：SFTP 面板右上角的 **⇅** 按钮（有任务时按钮上带一个数字角标），或 `Ctrl+Shift+J`。
- 每个文件一行：文件名、方向（上传/下载）、主机、进度条、`已传 / 总量`、百分比、**实时速度**、**剩余时间**。
- 大小读不出来时（远端不给）不假装知道：进度条变成来回扫的流动条，而不是编一个百分比。
- **可以取消**：取消会把流真正掐掉，并且**如实报告"已取消"**——半截文件不会被说成"完成"。
- 已完成的记录留在列表里（保留最近 40 条），一眼能看出是成功、失败还是被取消；「清除已完成」可以清掉。
- 关掉窗口不影响传输；传完了再打开也看得到结果。

速度/剩余时间是**在窗口里按两次读数算出来的**，不是主进程发的：它们属于"观察"这件事，而且窗口关着的时候
发这些值没有意义。

## 验证

完整闸门 `npm run verify`：41 套件全过。`smoke:drawer` 95 → **103 条**，新增 8 条走的是真 SSH 会话：

- 面板上的按钮能打开窗口，空列表时说明"现在没有任务"；
- 真传一个 4 KB 文件上去：列表里出现 `done`、大小和已传字节都等于真实大小、带主机名、行上显示 100%；
- 再真下回来：同一个列表里 upload / download 两条并存；
- 传一个 **48 MB** 文件并在中途取消：能抓到 `running`、角标显示 **1**、取消后状态是 `cancelled` 而不是
  `done`、已传字节小于总量（**真的停了**）、并且**返回给调用方的是 cancelled**（否则面板会弹"成功"）；
- 取消后角标消失，「清除已完成」把列表清空，窗口能关掉。
