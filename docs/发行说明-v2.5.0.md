# TermDeck v2.5.0

TermDeck 是一个 SSH / SFTP 终端客户端：可拖拽、可停靠的终端窗格，加上会话树、主机批量管理、
端口转发、对象存储与 REST 工具页。Windows 与 macOS 都有构建。

**v2.5.0 是终端体验的两处改进**：一是**后台窗格有新输出时看得见**（标签头与会话行上的活动
提示点）；二是修掉输出高亮的两处毛病 —— **IPv6 地址只被高亮半截**、**远端本来就有颜色的输出
被高亮盖掉**。

## 后台窗格有新输出时，看得见

多窗格开着的时候，不在前台的那个窗格开始打印（`tail -f` 有日志、`make` 跑完了、远端掉线
又回来），现在不用挨个点开看：

- **标签头上出现一个小圆点**（强调色），**侧栏「打开的会话」里那一行也有一颗**；
- 点开/切到那个窗格的那一刻，提示消失；
- **只在后台标**：你正看着的窗格自己打印不会标 —— 提示的意义是「别处有新东西」；
- 只有**真实输出**算数：窗格切回来时重放的积压内容、TermDeck 自己的「会话已结束」提示，
  都不会点亮它；
- 会话关掉后提示随之清理，不会留下一个指向空窗格的点。

圆点的颜色和会话行的连接种类点（绿=SSH / 橙=本地）分开：种类点说明「这是什么连接」，
活动点说明「这里有新内容」。

## 输出高亮的两处修复

- **IPv6 地址整段高亮**：以前 IPv6 地址要么完全不高亮，要么只亮一小截 ——
  `::ffff:192.168.1.1` 这类带 IPv4 尾巴的地址，只有尾巴那 11 个字符被框住，前面的
  `::ffff:` 是白的；`fe80::...`、`2408:8207:...` 这类纯 IPv6 则一个字符都不亮。
  现在**整段地址一次框住**，全形、压缩形（`2001:db8::1`）、带 `%` 网卡的
  （`fe80::1%en0`）、以及 `::ffff:` / `64:ff9b::` / `2001:db8::a.b.c.d` 这些嵌入式写法
  都在内。MAC 地址（`a1:b2:c3:d4:e5:f6`）仍归 MAC 规则，不会被当成 IPv6。
- **本来就有颜色的输出不再被盖掉**：远端自己上了色的文字是它有意发的信息 ——
  `ls --color` 的目录、构建脚本的红色报错、彩色提示符。高亮以前会把这些格子重涂成
  自己的颜色（红线里的 IP 被涂成高亮蓝）。现在**带颜色的整段跳过**，只在**没有颜色**的
  文本上高亮；同一行里没上色的普通 IP 照常框住。

## 其它

- 新增活动标识探针 **10 条**（后台标、前台不标、聚焦清标、再落后台再标、会话关掉清干净），
  高亮探针扩到 **27 条**（三种 IPv6 整段宽度、MAC 不被吞、红色输出零覆盖、其后普通 IP 照常）。
  两套都在**未实现这些改动的旧代码上实测退出码 1**。
- 快捷键、菜单、主题、主机导入（`~/.ssh/config`）等与 v2.4.0 一致。

## 已知边界（写在明处）

- **macOS 产物未签名、未公证**：第一次打开要右键「打开」，或
  `xattr -dr com.apple.quarantine /Applications/TermDeck.app`。
- **S3 页与端口转发页仍是英文界面**。
- 高亮的定位是「屏幕上这段文字」，所以：跨越换行的匹配不会跨行高亮；`vim` 这类使用
  备用屏的程序里不画高亮；**已经带颜色的输出按设计不覆盖**。
- 一个 IPv6 地址如果恰好是「六组两位十六进制」的尾巴（`fe80::a1:b2:c3:d4:e5:f6`），
  那段尾巴会和 MAC 地址语法相同，按 MAC 规则上色。
- `~/.ssh/config` 导入不支持 `Include` 通配、不支持 `Match` 条件块；跳板链（`ProxyJump`）
  不生效，只写入备注。
- Windows 只提供 x64 构建。

Get-FileHash -Algorithm SHA256 .\TermDeck-Setup-2.5.0.exe
```

shasum -a 256 TermDeck-2.5.0-arm64.dmg
```

和附件里对应的 `SHA256SUMS-*.txt` 对一下即可。
