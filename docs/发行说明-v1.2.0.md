# TermDeck v1.2.0（草稿，未打包）

这一批只有一件事，但它是终端客户端最基本的那件事：**断线之后，你刚才看的东西还在**。

## 新增

**重连之后，历史留着，窗格还是那个窗格**

以前会话一断，重连等于开一个新会话 —— 新会话就是新终端，屏幕清空，连刚刷出来的报错一起没了。
现在重连**沿用同一个会话**，终端实例不重建：上面打印过的一切原样留着，新连接直接往下写。

- 遮罩仍然覆盖整个窗格（半透明，上面的输出看得见），中间一个「重连」按钮，按下去就在原地连回去。
- 用了它当初连上去的那套参数，包括只在这个进程里存在过的密码 —— 临时连的机器也能一键回来。

**Ctrl+R 重连**

会话结束的窗格上按 `Ctrl+R` 就重连。**只在窗格已经结束时生效**：还活着的终端里 `Ctrl+R` 是 shell 的
反向搜索，和 `Ctrl+D` 一样，应用不抢这个键。

**被动断开自动重试（可设置）**

连接自己掉的时候（网络断了、对端消失），自动重试，遮罩上显示「第 1/2 次尝试 —— 1 秒后连接」，
随时可以停。

- 默认 **重试 3 次、每次间隔 10 秒**；在 **设置 → 终端 → 连接掉线** 里改次数和间隔。
- **只重试"自己断开"的连接**：你在 shell 里敲 `exit`、关掉窗格、按 `Ctrl+D`，那是你自己结束的，
  不会自己又连回去。
- 次数用完就停下并说明「已放弃」，手动重连按钮还在，不会再骚扰那台机器。
- 「一次掉线」内累计次数：连接稳定 10 秒以上才重新计数，所以对"能连上但马上又断"的主机也会在
  用完次数后停下。

**抽屉里的会话区可以搜了（名称 / 地址 / 标签）**

终端页左边抽屉的会话列表上方多了一个搜索框，三种都能搜：

- 名称（`web-1`）、地址（`10.9.8.7`，域名也一样）、标签（`staging`）。
- 搜索时只显示匹配的主机及其所在分组，空分组收起来；标签芯片和搜索框可以一起用，越搜越窄。
- 没匹配到会说一句，而不是给你一片空白；点 × 或按 `Esc` 恢复。

## 修复

- **vim / less 里不再弹命令补全**。补全现在只在 shell 提示符下出现：vim、less、man、htop、tmux 这类
  全屏程序会切到终端的备用屏幕，应用盯着这个切换 —— 进去时已经打开的补全立刻收起，在里面敲什么
  都不会弹，退出后照常。顺带修掉了「在 vim 里按回车会被记进命令历史」。
- **telnet 掉线被报成"正常退出"**：连接断掉时报的退出码是 0，让"掉线"和"你登出了"从外面完全分不
  出来（自动重试正是靠这个区分）。telnet 没有退出码，现在如实报告。
- **重连可能绑上一个已经死掉的会话**（telnet/串口这类"socket 一开就算成功"的传输），结果是提示消失、
  留下一个没有任何说明的死终端。现在只有会话确实还活着才算重连成功。

## 已知边界

- 判断"是不是命令行"用的是**备用屏幕**这一个信号（全屏程序进出都会切它）。像 `sudo` 的密码提示、
  `[y/N]` 确认这类**没有切屏、但不是命令行**的场合，终端层面拿不到可靠信号，补全仍可能出现；
  反过来，`less -X` 这种明确不切屏的全屏程序也识别不到。要更准就得读 shell 自己的提示符，那是另一
  件事（可以做，但不该顺手塞进这一版）。

## 验证

完整闸门 `npm run verify`：41 套件全过。这一次新增的断言：

- `smoke:reconnect` 30 条 —— 重连后 session id 不变、断线前打印的那一行还在、新连接写进同一个终端、
  Ctrl+R 在活着的窗格上不重连而在结束的窗格上重连、敲 `exit` 不会被自动重试。
- `smoke:transport` 19 条
- `smoke:drawer` 80 条 —— 会话区按名称 / 地址 / 标签搜索、无匹配时的提示、清除与 Esc 恢复。 —— mock 交换机支持主动挂断（HANGUP）和拒连（REFUSE）：挂断后自动重试
  自愈、同一会话；拒连时用尽次数后放弃并留下手动按钮。
