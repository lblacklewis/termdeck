# TermDeck 项目会话总结

一个 Electron 桌面 SSH 客户端：三栏布局 + dockview 可拖拽分屏终端。

## 📅 时间线

| 阶段 | 内容 |
|------|------|
| **第1轮** | 调研 WindTerm 的分屏拖拽 → 发现其公开仓库缺少主窗口/布局层 |
| **第2轮** | 转向自研：选定 Electron + React + TS，先跑通最小可用闭环 |
| **第3轮** | known_hosts 校验、加密凭据库、多层嵌套会话与标签、设置页 |
| **第4轮** | 修复双击连不上、右键菜单、连接窗口、底部快捷指令栏 |
| **第5轮** | 默认加密凭据、多套主题、窗口圆角化 |
| **第6轮** | 主题配色修正、点击预览、浅色对比度、整体精致化 |
| **第7轮** | 密码提示、新建会话按钮位置、快捷键右键、指令栏恢复 |
| **第8轮** | 三栏 + 导航轨 + 全部模态窗改抽屉、参考 Termius 配色 |
| **第9轮** | 快捷键右键真因、快捷指令不再自动换行 |
| **第10轮** | 修复连接后无窗格、布局持久化 |
| **第11轮** | 标签右键菜单、临时连接自动保存、输出另存为、时间戳 |
| **第12轮** | 字体可选、光标频闪、多窗口同时输入、风格精致化、移除行内图标 |

## 🏗️ 架构

```
Electron 主进程（独占特权）
  ├── ssh2               SSH 通道（静态 import，避免 CJS namespace 问题）
  ├── @lydell/node-pty   本地 shell
  ├── CredentialStore    safeStorage → AES-256-GCM，密文落盘
  ├── LayoutStore        layout.json（dockview 布局 + 页面/栏位状态）
  └── fonts.ts           平台字体枚举
        ↕ 单一窄 preload 桥（contextIsolation，无 nodeIntegration）
渲染进程（React 19）
  ├── dockview 8.3       分屏/分组；v7+ 无 React 绑定，自写 ReactRenderer
  ├── @xterm/xterm 6     终端
  └── broadcast.ts       多窗格同时输入
```

## 📝 主要文件

| 文件 | 说明 |
|------|------|
| `src/shared/types.ts` | 三进程共享类型（唯一事实来源） |
| `src/main/store/CredentialStore.ts` | 加密凭据；`set()` 为合并语义 |
| `src/main/store/LayoutStore.ts` | 布局持久化 |
| `src/main/ssh/KnownHosts.ts` | 指纹按 OpenSSH 规范算（keytype SP base64） |
| `src/renderer/src/App.tsx` | 应用外壳、页面、抽屉、右键菜单、布局 |
| `src/renderer/src/components/ReactRenderer.tsx` | dockview ↔ React 适配；含参数刷新注册表 |
| `src/renderer/src/components/terminalRegistry.ts` | 终端注册表、回滚缓冲读取、时间戳、光标闪烁 |
| `src/renderer/src/components/broadcast.ts` | 多窗格同时输入 |
| `src/renderer/src/components/useTheme.ts` | 主题 → CSS 变量；语义色与边框按主题派生 |

## ✅ 验证方式

`npm run verify` = typecheck + 15 个探针套件 + 11 套主题 × 5 页面 WCAG 对比度审计。

探针在真实 Electron 里驱动真实应用（真 PTY、真 SSH、真 DOM），不是只断言元素存在。

## ⚠️ 已知边界

- Termius 是闭源软件：**未复制其任何代码或素材**，仅参考通用布局模式。
- macOS 字体枚举未实现，会退回内置短名单。
- 密码型首次连接的「是否保存密码」提示未端到端验证（缺少密码；走的是同一条已验证的加密路径）。
- 探针依赖 `82.156.226.192` 作为 SSH 目标，可用 `TD_SSH_HOST` / `TD_SSH_USER` / `TD_SSH_KEY` 覆盖。
