# TermDeck v1.3.1

上一版（v1.3.0）的快捷指令已经包含在内，这里是在它之上修历史记录。

## 修复

**历史记录只收真正执行过的命令行**

以前抽屉里的历史记录会冒出 `-s`、`lssc-s` 这样的条目 —— 那不是谁执行过的东西，是把**按键**拼出来的
残渣。原因在记录方式：终端里的 Tab 补全、上下键召回都**不经过应用的输入路径**，所以"按过的键"和
"屏幕上那一行"会越差越远；一旦读屏幕失败就退回按键拼出来的文本，残缺的一行就被当成命令存了下来。

现在历史只认**屏幕上的那一行**（shell 实际收到并执行的那一行）：

- 读不出提示符到哪里结束，就**不记录**——漏一条是空白，记错一条是关于"我干过什么"的假话；
- 提示符的长度会在每条命令执行完、提示符重新绘制时重新测量，所以 `cd` 进更深的目录（提示符变长）
  之后依然准确；
- 上下键召回的历史行会让应用停止猜测长度，等你提交下一条命令再重新对齐，不会把召回的内容截掉；
- 存储层再兜一道：`-s` 这种只剩参数的、以空格开头的（shell 自己的"别记这条"约定）、以及还带着提示
  符的串，一律不收；同一份过滤也用在补全候选列表上，所以候选里也不会再出现碎片。

## 验证

完整闸门 `npm run verify`：41 套件全过。`smoke:suggest` 24 → 29 条，新增的 5 条直接冲着这次的问题去：
裸参数不收、以空格开头的不收、带提示符的不收、正常命令照旧收、补全候选里没有碎片。
