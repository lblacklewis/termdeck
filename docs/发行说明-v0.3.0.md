# TermDeck v0.3.0

中文界面、首次启动的欢迎页，以及数据放在哪里由你决定。v0.2.0 之后共 6 次提交。

## 新增

**中文界面**
- 全界面**简体中文**（363 条文案），设置 → 外观 → **语言**里切换，**选完立即生效**：
  导航栏、抽屉、菜单、设置页签、提示语一起变；不保存关掉就退回原来的语言，
  保存后重启仍然生效。
- 翻译的做法是**英文原文留在代码里当兜底**，词表只放译文 —— 少一条译文就退回英文，
  不会出现空白或原始 key。21 条**有意不译**：产品名、`Ctrl`/`Alt`/`Esc`、
  命令提示符、示例命令、字体预览样例。

**首次启动的欢迎页**
- 第一次运行（以及从旧版本升级上来的第一次）会问四件事：**语言 / 配色 / 终端字体 /
  数据保存位置**。四项都是**即时预览**，选完点「开始使用」写入并记下已看过。
- 主按钮固定在底部，只有中间一段会滚动，不会因为主题多而把按钮顶出屏幕。

**配置放在哪里由你决定**
- 默认仍是系统的用户目录，但可以在欢迎页或 设置 → 凭据 里**改到任意目录**
  （比如放到同步盘或移动硬盘）。
- 改动时会把设置、布局、会话、密码**复制**到新目录再重启（复制而不是移动：
  移动到一半是数据丢失类的 bug）。指针文件放在系统用户目录里，
  它指向的目录即使被删掉、拔掉了盘，也会安全地退回默认位置。

**终端**
- **会话结束后按 `Ctrl+D` 关掉这个窗格**。在活着的 shell 里 `Ctrl+D` 仍然是
  EOF（退出登录、REPL 都靠它）—— 这个绑定只在进程已经结束时生效，
  不会把 EOF 抢走。

## 改进

- **主机导入导出也放在 设置 → 凭据 → 主机备份**（和 Hosts 页工具栏是同一个对话框）：
  搬数据到另一台机器时，人就该在被搬的东西旁边找到它。
- 底部提示**1.2 秒自动消失**（原来要点击才走，十分钟前的消息会一直挂着，
  看着像当前状态）。

## 修复

- **点「当前已经在的那个页面」不再把左侧栏收起来**。它原来是切换（照 VS Code
  活动栏抄的），而新装的第一次恰好停在终端页 —— 点一下「终端」找找看，
  整列就收成图标条了，看起来就是「左边没了」。收起仍然是一个明确的手势：
  左下角开关或 `Ctrl+B`。
- **欢迎页的字体 chip 换一个不会取消上一个**：判断写成了「字体栈里是否包含这个名字」，
  而字体栈本来就带着自带的兜底字体，于是那两个永远亮着。
- 主题卡片上的 light/dark 小标签在 Paper 主题下只有 2.77:1，改成可读的颜色
  （对比度审计现在是 13 套 × 5 个页面全过）。

## 安装

| 文件 | 说明 |
| --- | --- |
| `TermDeck-Setup-0.3.0.exe` | 安装版（可选安装目录，快捷方式） |
| `TermDeck-0.3.0-x64.exe` | 便携版单文件，双击即用 |
| `TermDeck-0.3.0-win-x64-portable.zip` | 解压即用的目录版 |

首次运行会有 Windows SmartScreen 提示（未签名构建）：**更多信息 → 仍要运行**。

需要 Windows 10/11 x64。登录支持密码、密钥文件（在会话里选）与 ssh-agent；
所有连接由内置的 ssh2 直接建立，不依赖系统的 `ssh.exe`。

> 从 v0.2.0 升级：原有的主机、分组、会话、密码和快捷键都保留。
> 只有第一次启动会多看一眼欢迎页（数据目录必须是**在写入任何数据之前**选的），
> 点「开始使用」即可，不会改动已有数据。
