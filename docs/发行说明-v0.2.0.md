# TermDeck v0.2.0

第一个功能完整的版本。v0.1 之后共 35 次提交，下面是用户能看到的变化。

## 新增

**主机管理**
- **批量添加主机**：一次粘多行 `user@host:port`，自动去重，共用同一个密码。
- **加密分享**：Hosts 页的 Import / Export 把整棵树（分组、主机、标签、密码）
  打包成一个 `.tdshare` 文件 —— 先 gzip 再 AES-256-GCM，密钥用 scrypt 从口令派生。
  导入按「用户名 + 主机 + 端口」去重、同名分组复用、密码按本机新 id 重新封装，
  同一个文件导入两次不会翻倍。
- **删除还有主机的分组会先问一句**，并写清里面有几台主机、几个子分组。

**终端**
- **四款光标形状**（空心方框 / 实心块 / 竖条 / 下划线），默认空心方框。
- **自带字体**：界面固定用 Inter；终端内置 Roboto Mono 与 JetBrains Mono
  （各四个字重，SIL OFL 1.1），不再依赖系统是否装了。
- **SFTP 面板**、**命令历史**（每个 session 一个文件，保留 7 天）、**专注模式**、
  **广播输入**、**番茄循环 / 休息提醒 / 一键锁屏**。

**界面**
- **13 套主题**，新增粉色 **Blossom** 与亮色紫 **Lavender**；每套都通过对比度审计
  （13 套 × 5 个页面）。
- **界面缩放 80%–150%**（`Ctrl+=` / `Ctrl+-`），抽屉可停靠屏幕右侧、分区可拖拽/可隐藏。
- **快捷键**（Settings → Shortcuts 里都能改）：`Alt+1..9` 跳到第 N 个会话、
  `Alt+[` `Alt+]` 上/下一个会话、`Ctrl+B` 收起抽屉、`F11` 专注模式、
  `Ctrl+Alt+L` 锁屏、`Ctrl+Shift+B` 广播输入。
- 列表页顶部改成通栏筛选条 + 动作行的形状。

## 改进

- Hosts 页支持**卡片 / 列表**两种视图，并且**切页与重启后都记得**。
- 退出前二次确认（X / Alt+F4 / 菜单 / 快捷键），并写清会关掉几个连接。
- 休息提醒改成不打断的横条，并且等终端空闲再出现。
- 拖拽调整窗格时暂停逐帧 fit，拖动不再卡。

## 修复

- **重启后窗格点「重连」永远报 "no longer saved"** —— 恢复时读的参数是空的，
  改为读解析出来的布局 JSON。
- **终端被钉在 100×100、命令行被挤进 65px 高的容器**（两个竞态的真根因）。
- **窗格偶发塌陷**、子分组建了不显示、Hosts 页拖拽没反应。
- **复制连接出来的是本地 shell**，改为按原连接重建。
- 主题预览色条从第一个版本起一直是**空白**（元素存在但尺寸为 0）。
- 光标闪烁此前**一直是坏的**：动画等的是 xterm 只在它自己开关打开时才加的类。

## 安装

| 文件 | 说明 |
| --- | --- |
| `TermDeck-Setup-0.2.0.exe` | 安装版（可选安装目录，快捷方式） |
| `TermDeck-0.2.0-x64.exe` | 便携版单文件，双击即用 |
| `TermDeck-0.2.0-win-x64-portable.zip` | 解压即用的目录版 |

首次运行会有 Windows SmartScreen 提示（未签名构建）：**更多信息 → 仍要运行**。

需要 Windows 10/11 x64。登录支持密码、密钥文件（在会话里选）与 ssh-agent；
所有连接由内置的 ssh2 直接建立，不依赖系统的 `ssh.exe`。
