# TermDeck v0.3.1

修复 v0.3.0 里一个让「刚装好的第一次使用」几乎不可用的问题。如果你装了 v0.3.0，
请直接换成这个版本。

## 修复

- **空白工作区的那张提示卡片会盖住整个界面**：新装的第一次走完欢迎页之后，
  左侧的图标栏和抽屉都看不见了，屏幕中间只剩一张「TermDeck / Split / Group /
  Rearrange / New session」的卡片，看起来像是「进来啥都没有」。
  真因是**类名撞车**：外壳里那张空工作区卡片本来就叫 `.td-welcome`，
  而 v0.3.0 新加的首启欢迎页（整窗遮罩）用了同一个类名，于是那张卡片被套上了
  「铺满整窗、不透明」的样式，正好压在左侧栏和抽屉上面。
  首启欢迎页已改用自己的一组类名（`.td-onboard*`），卡片恢复成卡片。
- **左侧轨道左上角的 ▚ 被切掉一半**：品牌那一行是居中排版的，而「▚ TermDeck」
  比轨道宽度还宽 —— 居中排一个超宽的内容会在**两端**都溢出，于是标记的左半边
  被推到窗口外面。改成让名字先省略，标记不再被裁。

## 为什么 v0.3.0 没测出来

上一个版本的探针只断言了「左侧栏存在、没有处于收窄状态」——那个断言在 bug 存在
时**也是通过的**：元素确实在、坐标也对，只是被别的东西盖住了。现在加了真正的检查，
用 `elementFromPoint` 问「轨道那个位置上画出来的到底是轨道、还是别的什么」，
以及「抽屉那个位置上画出来的是不是抽屉」。

## 安装

| 文件 | 说明 |
| --- | --- |
| `TermDeck-Setup-0.3.1.exe` | 安装版（可选安装目录，快捷方式） |
| `TermDeck-0.3.1-x64.exe` | 便携版单文件，双击即用 |
| `TermDeck-0.3.1-win-x64-portable.zip` | 解压即用的目录版 |

首次运行会有 Windows SmartScreen 提示（未签名构建）：**更多信息 → 仍要运行**。

需要 Windows 10/11 x64。功能与 v0.3.0 相同（中文界面、首启欢迎页、可配置数据目录、
`Ctrl+D` 关闭已结束的会话），只多了上面的修复。
