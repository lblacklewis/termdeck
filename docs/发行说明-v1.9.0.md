# TermDeck v1.9.0

## 新增

**主机列表的分组可以折叠了**

主机几百台、分组几十个的时候，摊开的一整页是没法看的。现在每个分组标题左边有一个 **▸ / ▾**：

- 折叠后**标题还在**（组名、数量、"新建主机"的 + 都在），收起来的是**组里的主机和子分组**；
- 折叠的分组**仍然可以接收拖拽** —— 把主机拖到一个收起的分组上照样能归档，折叠是"看不见"，不是"用不了"；
- **筛选时自动展开**：搜索框或标签筛选一开，折叠全部失效、折叠按钮也不画 —— 筛出来的就是要找的那些，
  藏在折叠里只会读成"这台主机不见了"；
- 折叠状态**记在布局里**（`layout.json` 的 `hostsFolded`）：切到别的页面再回来、重启之后都还在。
  这是关键的一条：主机页在切走时会被卸载，状态放在页面自己身上就是"看一眼日志回来全开了"
  —— 这个坑在卡片/列表视图上已经踩过一次。

**一键折叠全部 / 展开全部**

分组多到一屏放不下时，一个一个点也不叫"方便"。在页面空白处**右键菜单**里（和"卡片 / 列表"放在一起）
有"折叠全部分组 / 展开所有分组"；筛选期间这两项是灰的（那时折叠没有可见效果）。

分组头的**右键菜单**没变（新建主机 / 新建子分组 / 重命名 / 删除），"+" 按钮的位置也没变。

## 决定（都写进交接文档了）

- **折叠态没有复用抽屉里会话树的 `SessionFolder.expanded`**，而是单独存在布局里。那是同一个文件夹树的
  **两个视图、两种用途**：在主机页收起二十个分组是为了看清库的结构，不应该让终端页的快速连接列表
  也跟着收起来。
- **折叠与展开都只改这一个字段**："全部折叠"是一次 `saveLayout`，不是对每个分组各发一次写盘。
- 折叠状态里的失效 id（分组被删掉了）**不清扫**：它们只在同名 id 再次出现时才有意义，而 id 是 uuid。

## 验证

完整闸门 `npm run verify`：41 套件全过、0 条 FAIL。`smoke:hosts` 57 → **73 条**，新增的 16 条读的都是
真实 DOM 与真实布局：

- 每个分组都有折叠控件，且**点一下真的把该组的主机从 DOM 里移除**（不是只把它藏起来 —— 那样搜索还会
  "找到"不在屏幕上的主机）、其他分组不受影响、`aria-expanded` 与 `data-folded` 都如实反映；
- 折叠**写进了保存的布局**，并且**离开页面再回来仍然折叠**（这条是防"页面自己的 state"那类回归的）；
- **搜索能钻进折叠的分组**，且筛选时不再提供折叠按钮；
- 右键菜单的**全部折叠/全部展开**：折叠后屏幕上没有一行主机，展开后回到原有行数；
- **折叠的分组仍然收得下拖进去的主机**（拖拽落在分组这一层，不因折叠而消失）。

证据：探针先写在**未改动的代码**上跑 —— 60/67，新增的 10 条里有 **7 条 FAIL**（另外三条在守卫里，
只在功能存在时才执行）。首次通过后又修掉一条我自己写错的断言：**"离开页面再回来折叠还在"在旧实现上是
恒真的**（没有折叠时"3 行 == 3 行"照样成立），正是交接文档里禁的那类断言 —— 现在它把"确实折过"
写进了前提。
