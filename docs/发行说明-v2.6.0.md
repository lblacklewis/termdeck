# TermDeck v2.6.0

TermDeck 是一个 SSH / SFTP 终端客户端：可拖拽、可停靠的终端窗格，加上会话树、主机批量管理、
端口转发、对象存储与 REST 工具页。Windows 与 macOS 都有构建。

**v2.6.0 是 REST 工具页的整体重做**（照 Apifox 的形状，只保留终端客户端用得上的部分），
外加三处终端体验修复：**长硬件地址整段高亮**、**点标签切过去就能直接打字**、
**标签上的 Backspace 不再把会话关掉**。

## REST 工具页：照 Apifox 重做

以前它是一张长表单 + 一个扁平的"已保存请求"下拉框，只能当个临时探针用。现在是一个**工作台**：

### 左边是接口集合

- **文件夹**：新建、展开收起、重命名、删除；**请求可以移动到某个文件夹**；
- **请求条目**：带方法色块，点一下进编辑器，可以就地重命名、删除；
- **筛选框**：按名字或 URL 过滤；**历史**在下面（点一下载入编辑器、★ 收进集合、可清空）；
- 一条要写明的规则：**删掉文件夹不会删掉里面的请求** —— 它们回到上一层，不会被顺手丢掉。

### 环境与 `{{变量}}`

- 环境管理对话框：新建 / 改名 / 删除环境，变量表带**启用开关**；
- 请求里写 `{{base}}/pets`，发送时按**当前选中的环境**替换（地址、请求头、参数、正文里都能用）；
- **变量没定义就拒绝发送并点名说缺哪个**，而不是把 `{{base}}` 当路径发出去换来一个 404；
  变量"临时关掉"等同于没定义；
- 编辑时就会提示"这个环境里没有：xxx"，不用等发送才发现拼错。

### 请求区：Params / Headers / Body / Auth 四个分页

- **Params**：表格与 URL 是同一件事的两个视图 —— 往 URL 里敲查询串会填进表格，改表格会改写 URL；
  **关掉某一行只是这次不发**，行还在（和删除区分开）；
- **Headers**：逐条编辑与"一整个 JSON"两种方式，切页带着数据走；单引号粘进来的对象
  （`{'Content-Type': 'application/json'}`）也能读；真写错了会明确报错，不会静默少一个认证头；
- **Body**：无 / JSON / 表单 / 文本四种模式；JSON 模式有格式化（不是 JSON 会说清楚）；
  往空的正文框里打字会**自动挑一个模式**，不会出现"屏幕上有正文却没发出去"；
  表单模式按 `application/x-www-form-urlencoded` 发送；
- **Auth**：无 / Bearer Token / Basic 认证 / API Key；**你自己手打的同名请求头优先**，
  auth 分页不会覆盖它。Basic 的用户名密码按 UTF-8 做 base64（中文用户名也对）。

### 响应区：正文 / 响应头 / Cookie

状态码、耗时、大小、跳转后的最终地址、失败原因；正文可搜索（带命中行数）、长正文折回；
**Cookie 分页**把每个 `Set-Cookie` 读成名字 / 值 / 属性 —— 一次响应设多个 cookie 时**各自成行**
（以前重复的响应头会被逗号粘成一条，`Expires` 里的逗号会让解析出鬼）。

### cURL 导入导出

「复制为 cURL」照旧；新加**导入**：把服务文档里的 `curl` 命令粘进来，方法、地址、参数、
请求头、请求体、`-u` 认证、`-k`（忽略证书）都会读进编辑器。读不懂的行**在框里说原因**，
不会导入一半 —— 尤其是 `-F` 上传：这里没有文件上传的落点，明确拒绝而不是装作成功。

## 三处终端修复

- **长硬件地址整段高亮**：InfiniBand / SR-IOV 那种一长串 `a0:00:02:...`（十几二十组）以前只有
  前六组被框住，现在整段一次框住。
- **点标签切过去就能打字**：用快捷键切换会话时键盘直接进终端，但**用鼠标点标签**以前还要再点一下
  终端才能输入；现在两种方式一致，点完标签键盘就落在那个窗格的终端里。
- **标签上的 Backspace 不再关会话**：dockview 自己把焦点标签上的 `Delete`/`Backspace` 当成"关标签"，
  于是点一下标签再按删除键会**把整个会话关掉**。现在这两个键在标签上被拦下并交回终端（真正想关
  会话用标签上的关闭按钮或菜单）。

## 内部修复（这轮自己抓出来的）

- **REST 请求的超时与"接受自签名证书"没有随请求发出**：界面上把超时改成 1 秒，实际仍是默认 15 秒。
  现在这两个设置跟着请求一起走。
- **环境里刚点「+ 变量」的那一行会消失**：存储层把还没起名字的变量行当垃圾过滤掉了，于是"点一下
  再打字"中间那行凭空不见、接着敲的字写进了上一行。现在空行保留到你自己删。
- **重复的响应头被 Node 折叠成一条**：多个 `Set-Cookie` 以前会被逗号拼起来，Cookie 分页因此不准。

## 已知边界（写在明处）

- **macOS 产物未签名、未公证**：第一次打开要右键「打开」，或
  `xattr -dr com.apple.quarantine /Applications/TermDeck.app`。
- **S3 页与端口转发页仍是英文界面**。
- 高亮的定位是「屏幕上这段文字」，所以：跨越换行的匹配不会跨行高亮；`vim` 这类使用
  备用屏的程序里不画高亮；**已经带颜色的输出按设计不覆盖**。
- 一个 IPv6 地址如果恰好是「六组两位十六进制」的尾巴（`fe80::a1:b2:c3:d4:e5:f6`），
  那段尾巴会和 MAC 地址语法相同，按 MAC 规则上色。
- REST 工作台不做 Mock、自动化测试、性能测试、请求脚本、数据结构文档 —— 这些是**有意不做**的，
  不是一个还没填的坑。
- 请求分页的当前位置不持久化（切到别的工具页再回来，编辑器回到参数页）；集合树暂不支持拖拽排序。
- `~/.ssh/config` 导入不支持 `Include` 通配、不支持 `Match` 条件块；跳板链（`ProxyJump`）
  不生效，只写入备注。
- Windows 只提供 x64 构建。
