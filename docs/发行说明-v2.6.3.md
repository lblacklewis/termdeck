# TermDeck v2.6.3

TermDeck 是一个 SSH / SFTP 终端客户端：可拖拽、可停靠的终端窗格，加上会话树、主机批量管理、
端口转发、对象存储与 REST 工具页。Windows 与 macOS 都有构建。

**这一版修三处界面问题**，都在日常使用里能碰到：

1. **拖选文字时高亮框偏一格** —— 高频出现，把字体换成自己喜欢的字体后更明显（见下）；
2. **终端补全弹窗里的长路径看不全** —— 候选末尾被省略号截掉，两个只差最后一个目录名的候选长得一模一样；
3. **主机管理页说"这个分组里还没有主机"** —— 而主机其实就在它的子分组里，同时下面又列着这些主机。

> v2.6.1 / v2.6.2 只动了 macOS（字体族名解析、打包架构、安装包签名），所以 **Windows 用户这一版
> 从 v2.6.0 直接跳到 v2.6.3**，界面上的变化就是上面这三条。

## 修复

### 1. 划词选择与鼠标所指的位置差一格

终端里拖选文字，画出来的高亮块落在鼠标旁边而不是鼠标底下。单窗口偶尔出现，分屏里几乎是必现。

真因不在 xterm 里，而在样式表的**继承链**上：`body` 上有一条全局 `letter-spacing: 0.01em`（为了让
界面文字松一点），而 `em` 是**跟着字号走**的，于是它一路继承进了终端。xterm 按"字符宽度 = 单元宽度"
来排版和测量，多出来的那一点点字距让**画出来的字形**比它所属的**单元格**宽一点点 —— 每格都偏一点，
越往右越明显。选区的坐标算的是字形，命中的是单元格，于是对不上。字体越宽、字号越大，偏得越多，
这也是换了自己的字体之后更明显的原因。

修法是把这个继承钉死：终端子树里 `letter-spacing: normal`，界面其余部分照旧。
`smoke:geom` 现在按住这件事 —— 它断言画出来的字形步进与单元格宽度一致、并且按字形拖拽命中的
就是鼠标下面那一格（**分屏里同样成立**）。

### 2. 补全弹窗里的长路径

敲一条很长的路径（补全列表里有更长的历史命令）时，弹窗会有一截挂在窗格外面被裁掉，
而且每一行都是**末尾**被省略号截掉 —— 而"两个候选只差最后一个目录名"恰恰是最常见的情况，
看起来就像同一条。

两处都改了：弹窗现在会被**夹在窗格内**，不再跟着光标探出去；候选按弹窗可用宽度**只省略中间**，
首尾都留着，所以 `…/deep/nested/folder/one` 与 `…/folder/two` 一眼能分清。已输入的前缀仍然是暗色，
后面会补上的部分仍然是亮色。

### 3. 主机管理页的空状态与分组计数

空状态原来只看分组的**直接**主机数。分组里没有主机、主机都在子分组里时，这个分组会一边写
"这个分组里还没有主机"，一边在下面把子分组里的主机列出来 —— 看起来像库里的会话丢了。
现在有子分组就不出这条提示，提示归**最深那层**（真正空的那一层才是能操作的那一层）；
标题右边的计数也改成**含子分组的总数**，与左侧会话树的口径一致（以前父分组会显示 0）。

## 已知边界（写在明处）

- **macOS 包仍未正式签名**：没有 Apple 开发者账号，首次打开要右键「打开」或 `xattr` 放行。
- **v2.6.1 的 mac 产物是坏的**（签名无效，双击报「已损坏」），那一页已标注，请改用 v2.6.3。
- S3 页与端口转发页仍是英文界面。
- 只有 Windows x64 与 macOS 两个架构；没有 Linux 官方产物。

```

shasum -a 256 TermDeck-2.6.3-arm64.dmg
```

和附件里对应的 `SHA256SUMS-*.txt` 对一下即可。
