# TermDeck v1.3.0（草稿，未打包）

## 新增

**快捷指令可以有自己的全局快捷键**

每条快捷指令都能挂一个快捷键，设一次，任何地方按下去就执行 —— 不用先去点那个按钮。

- 在快捷指令的编辑器里录一次即可（点「快捷键」那一格，按下组合键，`Esc` 放弃）。
- 它和内置快捷键共用同一套规则：终端里正在输入时按下也会触发，`Esc`/方向键这类单键不会被抢。
- 删掉快捷指令，它的快捷键一起消失 —— 不会留下一个按下没反应的键。

**快捷键冲突会被拦下来**

设置 → 快捷键里，若同一个组合被两处占用（两个快捷指令、或者快捷指令撞上内置功能），会：

- 在列表上方逐条写出「`Ctrl+T` 被 New connection 与 hotkey-run 同时使用」；
- 把用到这个键的那一格标红；
- **拒绝保存**：先改掉冲突再存，而不是让你保存完发现某个键"有时灵有时不灵"。

快捷指令的快捷键也会出现在这张列表里（就在内置项下面），因为终端层面它们是同一个派发器，抢的是同一批键。

## 修复

- **点了快捷指令之后，光标回到窗格**。以前点完按钮焦点留在按钮上，下一次敲键盘什么都不会发生 —— 得先用鼠标点回终端。现在发送完直接把焦点还给命令进去的那个终端，可以接着打字。
