# TermDeck v1.13.0

## 改进：Ctrl+W 交还给 shell

`Ctrl+W` 在 readline 系（bash / zsh / Python / Node REPL）里是**删掉光标前一个词**，是肌肉记忆。
TermDeck 以前把它绑在"关闭当前会话"上，于是这个键被吃掉了——探针实测旧代码按下它时，
终端**拿不到 0x17**，会话从 1 变 0、窗格也没了。

- **默认不再绑定**（动作仍留在快捷键列表里，想用的人自己设一个）。
- **光改默认值不够**：每个跑过 TermDeck 的机器上，存盘里都躺着旧的 `Ctrl+W`。所以加了迁移
  `RETIRED_BINDING_DEFAULTS` —— **只在值恰好是旧默认时**改写；用户自己改过的（比如
  `Ctrl+Shift+W`）原样保留。

## 新增：设置里显示版本号

设置底部操作栏左侧常显 `TermDeck v1.13.0`，鼠标悬停显示 Electron / Chromium / Node 版本。
"我是不是最新版"这个问题通常是在设置里问的，答案得能一眼看到、也能截图给别人看。

顺带修掉一个会显示错版本的坑：`app.getVersion()` 在"把 Electron 指向脚本"启动时（探针、dev）
会回落到 **Electron 的版本**，界面会写成 `TermDeck v33.4.11`。现在按顺序找应用自己的
`package.json`（`app.getAppPath()` / 工作目录 / 分块往上三级），用包名校验，最后才回落。

## 新增：结束/重连的遮罩可以直接关掉，关掉就不再重试

会话结束、自动重连正在倒计时的那块遮罩，以前只有「重连」和「停止重试」两个按钮，
要彻底摆脱这个死窗格只能去点标签上的 ✕ 或者按快捷键。现在遮罩上多了**「关闭窗格」**：

- 关掉 → 窗格和它的会话一起消失；
- **并且不再自动重试**。按钮先停掉重试循环再关窗格——顺序是刻意的：如果先关窗格，
  一个已经发出去的重连请求会回到一个不存在的窗格上。

## 探针里踩到的坑（记录）

1. **注入脚本的注释里不能出现反引号** —— 又把模板字符串提前闭合了一次（这次报的是
   "missing ) after argument list"）。铁律就是这么来的。
2. **别用 `defaultPrevented` 判断"按键有没有被应用吃掉"**：xterm 对自己转发的键**也会**
   preventDefault，所以那个标志永远为真，测不出东西。要看的是**终端数据通道有没有吐出那个字节**——
   应用的快捷键匹配器是捕获阶段 + `stopPropagation`，被抢走的键根本到不了 textarea。
3. **顺序会影响结论**：探针里"真按键"那几条必须跑在写设置之前。第一版把它们排在迁移测试之后，
   而迁移测试自己把绑定写成了空 —— 于是旧代码上也照过，等于自证。
