# TermDeck v0.4.0

命令历史补全、已知主机批量操作，以及一组让「应用里的快捷键终于说了算」的修复。
v0.3.0 之后共 8 次提交。

> v0.3.1 那个标签没有单独发布过，所以下面「修复」里也包含它本来要带的内容
> （左上角那张空白工作区卡片盖住侧栏、轨道品牌标记被裁）。

## 新增

**命令历史补全（WindTerm 风格）**
- 开始输入就按前缀弹出你**跑过的命令**，`↑`/`↓` 选择，`Enter`（或 `Tab`）把它带进
  命令行 —— **只是填进去，不会执行**；`Esc` 关掉。弹出层关着时 `↑`/`↓` 完全不受
  影响，shell 自己的历史照旧能用。
- 候选是**所有 session 共用**的一份历史：想找的那条命令，往往是在另一个窗格里跑过的。
- 补全只写「剩下的部分」：输入 `git sta` 选中 `git status --short`，实际只发送
  `tus --short`。
- **存储规则按「密码优先」定**：以**空格开头**的行不记录（shell 的「别记我」约定，
  也是打错的密码最容易被写进明文文件的方式）；空行、相邻重复、超过 240 字符的
  也不记；总量上限 400 条，重复命令会置顶而不是堆一份。

**已知主机批量操作**
- 已知主机页每行加了复选框、表头有全选，选中后可以一次**忘记 N 个**（会先确认）。
  主机重装或换过密钥时，一次清掉一批，不用一个个点。
- 选择集会跟着过滤条件收缩：「已选 2」永远等于你**看得见**的那 2 行。

## 改进

- **`Ctrl`+`=` / `-` 现在只改终端里的字体**（8–32px，和设置里同一档），不再把标签栏、
  抽屉、对话框一起放大缩小。**界面缩放移到 `Ctrl`+`Shift`+`=` / `-`**，设置 → 外观
  里也照旧能选。
- 列表页、设置里的按钮行排版统一（批量操作按钮和「重新载入」同一行）。

## 修复

- **`Ctrl`+`W` / `Ctrl`+`D` 在终端里根本收不到**。xterm 会在它自己的输入框上处理按键
  并对它处理的键阻止冒泡，所以应用挂在冒泡阶段的快捷键监听从来没被调用过 ——
  `Ctrl`+`W` 被当成「删掉一个词」送进 shell。快捷键改为在**捕获**阶段生效：应用的
  绑定先于终端，而「活的 shell 里 `Ctrl`+`D` 仍然是 EOF」这条也照旧成立。
- **断线后 `Ctrl`+`D` 没反应**：判断从「我看到会话结束了」改成「这个窗格后面没有活着
  的会话」—— 掉线的 SSH、重启后恢复的占位窗格、已经退出的 shell 都算。
- **断线后右键 Reconnect 失败**：它去复制一个后端已经不存在的会话，失败就把后端错误
  弹出来。现在失败时**回退到保存的主机重新连**，并且重连成功后不再丢掉「这条连接来自
  哪台主机」的记录（丢掉就等于删掉了下次还能重连的唯一线索）。
- **空白工作区的那张提示卡片会盖住整个界面**（v0.3.0 的严重问题，本该由 v0.3.1 修）：
  走完欢迎页之后左侧栏和抽屉全不见了，屏幕中间只剩一张卡片。真因是**类名撞车** ——
  新加的首启欢迎页和外壳里那张卡片用了同一个类名，于是卡片被套上了「铺满整窗、
  不透明」的样式。
- **轨道左上角的 `▚` 被切掉一半**：品牌行居中排版，而「`▚ TermDeck`」比轨道宽，
  居中排超宽内容会在两端同时溢出。
- 欢迎页的字体 chip 换一个不会取消上一个；主题卡片上的 light/dark 小标签在 Paper
  主题下只有 2.77:1，改成可读的颜色；点「当前已经在的那个页面」不再把左侧栏收起来。

## 安装

| 文件 | 说明 |
| --- | --- |
| `TermDeck-Setup-0.4.0.exe` | 安装版（可选安装目录，快捷方式） |
| `TermDeck-0.4.0-x64.exe` | 便携版单文件，双击即用 |
| `TermDeck-0.4.0-win-x64-portable.zip` | 解压即用的目录版 |

首次运行会有 Windows SmartScreen 提示（未签名构建）：**更多信息 → 仍要运行**。

需要 Windows 10/11 x64。登录支持密码、密钥文件（在会话里选）与 ssh-agent；
所有连接由内置的 ssh2 直接建立，不依赖系统的 `ssh.exe`。

> 从 v0.3.0 升级：原有的主机、分组、会话、密码、主题与快捷键都保留。
> 命令历史从这一版开始记（旧版本的历史文件仍在，补全列表会随着你继续用而长出来）。
