# TermDeck v1.10.0

## 新增

**抽屉「会话」里一键折叠 / 打开所有分组**

终端页左侧抽屉的会话树一直能单个分组折叠（点分组名），但分组一多，**一个一个点不叫整理**。
会话区标题右边多了一个按钮：

- 有分组展开着时显示 **▾▾**，点一下**把所有分组收起来**（嵌套的也一起收）；
- 全部收起后显示 **▸▸**，点一下**全部打开**；
- 收起的是分组，**根目录下的会话照旧列着** —— 折的是"分组"这个维度，不是整个列表；
- 状态**按分组存**（`SessionFolder.expanded`），不是存在页面里：切到别的页面再回来、重启之后都还在；
- **一次写盘**：整个操作是一条 IPC、一次 `sessions.json` 写入、一次广播。逐个分组改的话，三十个分组
  就是三十次写盘和三十次重绘，一边点一边看着列表抖。

**顺手修掉一个真 bug：搜到的会话藏在折叠分组里就看不见**

以前在抽屉里搜索时，**折叠着的分组不会因为搜索而展开**：分组标题上是匹配的、里面却是空的，
所以"我明明搜到了这台机器"变成"这台机器不见了"。现在**筛选期间所有分组强制展开**，折叠控件收起不画、
点击也不折叠（那时候没有可折叠的东西，点了却默默改一个看不见的状态才是骗人）。

这个 bug 在加了"一键折叠全部"之后会从边角情况变成常态 —— 先折全部再搜索，什么都搜不到 —— 所以两件事一起做。

## 决定（写进交接）

- **批量折叠做在主进程**（`SessionStore.setAllFoldersExpanded`，一次 commit），不是在渲染层循环调用
  `saveFolder`。理由就是上面那条：写盘与广播各只有一次。
- **按钮放在会话区标题的动作区**（和"新建会话 / 新建分组"一起），而不是右键菜单：这是"一键"，藏进
  右键菜单就不是一键了。
- **筛选时禁用而不是隐藏**：标题栏里的按钮消失会让标题左右跳一下；置灰既不动布局，也说明"现在没得折"。
- 折叠方向读的是**存储里的状态**（任一分组 `expanded !== false` 就是"有展开的"）。注意嵌套分组即使
  被父分组藏起来了，它的 `expanded` 仍然算数 —— 这正是"一键折叠"比手工逐个点强的地方。

## 验证

新套件 `smoke:treefold`（**12 条**，读真实 DOM 与真实存储）。先写在**未改动的代码**上跑：**5 条里 2 条 FAIL**
—— 一条是"按钮不存在"，另一条是那条既存缺陷本身（`folded=true edge-1=hidden`）。

覆盖：
- 搜索能钻进折叠的分组（这条在旧实现上必挂）；
- 一个控件折叠全部分组，**嵌套的也在内**，且**存储里三个分组的 `expanded` 全是 false**；
- 再点一次全部打开；
- 根目录下的会话不受影响；
- 筛选期间控件在但被禁用，清空搜索后重新折上。

完整闸门 `npm run verify`：**42 套件**全过、0 条 FAIL（新套件进闸门）。抽屉原有那套 `smoke:drawer`
123 条未变 —— 强制展开只在筛选时生效，平时行为一个字没动。
