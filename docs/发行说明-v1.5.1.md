# TermDeck v1.5.1

## 改进

**传输进度改成快捷指令上方的一条常驻横条**

上一版把进度放进了「传输窗口」，可它的入口是 SFTP 面板里五个图标中的一个，只有面板正好开着才看得见 ——
找不到是必然的。现在：

- **有传输开始时，快捷指令栏上方自动出现一条横条，并自动展开**，不需要去哪个面板里找。
- 收起来也读得出在传什么：文件名、方向、百分比、总速度。展开就是完整列表（速度、剩余时间、取消都在里面）。
- 全部传完自动收起，不拿一屏已完成记录占着终端；随时点 ⌄ / ⌃ 展开。
- **✕ 只是隐藏**，传输继续跑；之后任何新任务会把它重新带回来 —— 关一次就再也看不到进度是真会发生的。
- **⌫ 一键清除**：清掉已完成的记录。进行中的不会被删（删了就成了没人能取消的传输）；清空后横条自己消失。
- **⤢ 打开原来的传输窗口**（`Ctrl+Shift+J` 仍在）。横条和窗口共用同一份行渲染，不会各长一套。

## 验证

完整闸门 `npm run verify`：41 套件全过。`smoke:drawer` 103 → **114 条**，仍走真 SSH 会话：

- 传输一开始横条就出现，并且**折叠状态下就能读出文件名与百分比**；
- 几何断言：横条底边在快捷指令栏顶边之上（不是盖住它）；
- ⌄ 折叠会收起行、再点展开行回来；
- ✕ 隐藏后 DOM 里没有横条；随后再传一个文件，**横条自己回来**；
- ⌫ 一键清除后列表为空、横条也消失。
