# TermDeck v1.0.0

窗格排列、命令历史改成记「真正执行的那一行」，以及一次把首屏 JavaScript 减半的性能整理。
v0.4.0 之后共 25 次提交。1.0 不是功能翻新，是把这一路攒下来的东西收干净：
**窗格怎么摆、命令怎么记、界面不挡内容**。

## 新增

**一键排列窗格**（`Ctrl`+`Shift`+`T`，或标签右键 →「排列窗格…」，或抽屉底部工具条的 ▦）

- 弹出框默认**全部勾选** —— "把我的窗口排一下" 绝大多数时候就是这个意思，可以取消掉不想动的。
- 四种排法：**瓷砖排列**（自动分成接近方形的网格）、**竖屏分割**（左右并排，每列占满高度）、
  **横屏分割**（上下排列，每行占满宽度）、**并成单个窗口**（全部合并成一个窗口的标签页）。
- **选几个就分几屏**：选中的等分成 N 屏，**没选中的并进最后一屏当标签页**，不会被挤成一条，
  也不占独立位置。
- 排列是**移动**面板而不是重建布局，所以正在跑的会话一个都不会断；分完按等宽等高铺开。

**面向用户的功能手册** —— `docs/使用手册.md`

从第一次连接、窗格操作、片段与广播，到快捷键、主题和故障处理，跟着做一遍就能用起来。

## 改进

- **命令历史记的是「执行的那一行」**。以前记的是按键流：用 `↑` 召回再改、或者靠 `Tab` 补全出来的
  命令，记下来是半截（`lssc` + `Tab` + `-s` 会记成 `lssc-s`）。现在在回车的瞬间从屏幕上读回光标
  所在行，Tab 补全和历史召回的结果都算在内，存的就是 shell 真正要执行的那一行。
- **脏历史会自己清掉**：带提示符残留的老记录（旧版本存过 `D:\...>Get-Dat` 这类）在读取时被丢弃，
  老文件不需要手动处理。
- **补全不再抢键**：只有 `Enter` 接受候选（`Tab` 完全还给 shell），弹出时默认不选中任何一项，
  继续输入就会自己收起。设置 → 终端 新增「输入时提示历史命令」开关，关掉后弹出层完全不出现，
  命令照旧记进历史。
- **右上角的浮层按钮删掉了**：同屏输入 / 时间戳 / 排列三个开关挪到抽屉底部工具条（⇶ / ⏱ / ▦），
  和会话操作放在一起，**不再盖住终端头几行输出**。
- **滚动条跟随主题**：包括 xterm 自己画的那条和 SFTP 等面板 —— 之前深色主题下会露出一条
  Chromium 默认的浅色条。
- 保存设置后抽屉自动关闭（以前留在原地显示 "Saved"，还挡着终端）。
- **滚动缓冲默认 10,000 → 4,000 行**。它是每个窗格常驻内存的最大单项；需要更长时设置里仍然可以
  调到 1,000,000，**已经显式设过值的老配置不受影响**。

## 修复

- **点「当前已经在的那个页面」现在收起 / 再点展开左侧栏**。上一版为了避免首启误会改成"只展开"，
  而首启的根因已经在欢迎页那侧修掉了，手势恢复成正常行为。
- **排列只选一部分时，没选中的窗格会被挤扁** —— 现在并进最后一屏当标签页。
- 「选 3 个却分成了 4 屏」：等分只按选中数量算。

## 性能

- **首屏 JavaScript 2.15 MB → 1.06 MB（−49.5%）**。两件事：
  - 设置抽屉、主机页、已知主机页、片段页、日志页、SFTP 面板改成**按需加载**（第一次打开时才载入）；
  - renderer 打包这一版开始**压缩**（`electron-vite` 默认不压缩，之前发出去的是 2 MB 未压缩代码）。
- CSS 同步从 277 kB 降到 207 kB；启动时不再解析你此刻看不见的那些页面的代码。
- 以上都不改变行为：页面第一次点开时多一次本地文件读取，之后和以前一样。

## 安装

| 文件 | 说明 |
| --- | --- |
| `TermDeck-Setup-1.0.0.exe` | 安装版（可选安装目录，快捷方式） |
| `TermDeck-1.0.0-x64.exe` | 便携版单文件，双击即用 |
| `TermDeck-1.0.0-win-x64-portable.zip` | 解压即用的目录版 |

**首次运行会弹「Windows 已保护你的电脑」** —— 这是 SmartScreen 对**未签名**且**从互联网下载**的
文件的默认拦截，不是报毒。三种处理方式：

- 弹窗里点 **更多信息 → 仍要运行**（一次性）；
- 先解除下载标记就不再多问：右键文件 → **属性** → 勾选 **解除锁定**，或者
  `Unblock-File .\TermDeck-1.0.0-x64.exe`。**解压前**先对 zip 解除锁定最省事（Windows 会把标记
  传给解压出来的文件）；
- 核对 SHA256（发布页附了三个文件的校验值）：

  ```powershell
  Get-FileHash .\TermDeck-1.0.0-x64.exe -Algorithm SHA256
  ```

单文件便携版每次启动都会先解压到临时目录，所以最容易反复触发；给人分发时优先给 **zip** 或
**安装版**。要彻底不再提示需要代码签名证书，细节写在 `docs/安装与信任.md`。

需要 Windows 10/11 x64。登录支持密码、密钥文件（在会话里选）与 ssh-agent；所有连接由内置的
ssh2 直接建立，不依赖系统的 `ssh.exe`。

> 从 v0.4.0 升级：主机、分组、会话、密码、主题、快捷键、片段全部保留。滚动缓冲的新默认值只对
> 没有显式设过 scrollback 的配置生效。命令历史文件仍在，补全列表会随着继续使用长出来。
