# 安装与「Windows 已保护你的电脑」

运行 TermDeck 时弹这个，**不是杀毒报毒**，是 Windows Defender SmartScreen 对
「**未签名** + 从互联网下载的文件」的默认拦截：

```
Windows 已保护你的电脑
Microsoft Defender SmartScreen 阻止了无法识别的应用启动。
运行此应用可能会导致你的电脑存在风险。          更多信息   运行
```

## 一、现在就能用（三选一）

**1. 直接放行（最快）**

在弹出的窗口里点 **更多信息** → **仍要运行**（截图里那个蓝色「运行」就是这一步）。

**2. 先解除下载标记，之后不再问（推荐）**

Windows 会给每个从浏览器下载的文件打一个 `Zone.Identifier` 标记，SmartScreen 正是
看它才拦的。去掉它就不再提示：

- 图形界面：右键文件 → **属性** → 常规页最下方 → 勾选 **解除锁定** → 确定
- 一行命令（PowerShell，在文件所在目录里）：

  ```powershell
  Unblock-File .\TermDeck-0.4.0-x64.exe
  ```

**解压之前先解除 zip 的锁定**最省事 —— 现代 Windows 会把标记传给解压出来的文件，
所以先 `Unblock-File .\TermDeck-0.4.0-win-x64-portable.zip` 再解压，里面的 exe 就不会
再弹。解压完也可以对整个目录跑：

```powershell
Get-ChildItem -Recurse | Unblock-File
```

**3. 校验一下再跑**

三个安装包都是本地构建的，可以在发布页对着 SHA256 核对：

```powershell
Get-FileHash .\TermDeck-0.4.0-x64.exe -Algorithm SHA256
```

## 二、为什么每次都要问

SmartScreen 的判定看两件事：

1. **有没有 Authenticode 签名** —— 我们现在没有证书，所以显示「未知发布者」；
2. **这个文件有没有下载信誉** —— 未签名文件要下载量攒够才会慢慢不再提示。

对**单文件便携版**（`TermDeck-x.y.z-x64.exe`）最容易反复触发：它每次启动都先解压到
临时目录。所以给人分发时优先给 **zip** 或 **安装版**，它们只在下一次下载时问一遍。

## 三、根治：代码签名证书

这是唯一能让 SmartScreen 完全不弹的办法，需要买证书（与代码无关，只是给构建签名）：

| 方式 | 大致成本 | 说明 |
| --- | --- | --- |
| **Azure Trusted Signing** | 约 ¥70/月起，需通过组织验证 | 目前最省事：云签名、不用买 U 盘（硬件令牌） |
| **OV 证书**（Sectigo/DigiCert 等） | 约 ¥1500–3000/年 | 仍需攒下载信誉才完全不弹 |
| **EV 证书** | 约 ¥3000–5000/年 + 硬件令牌 | 有证书即**立即**获得 SmartScreen 信誉 |

拿到证书后**不需要改代码**：electron-builder 直接认这几个环境变量。

```powershell
# 证书文件（.pfx）与密码，构建时由 electron-builder 自动使用
$env:CSC_LINK = 'C:\path\to\termdeck.pfx'
$env:CSC_KEY_PASSWORD = '你的证书密码'
npm run pack:zip
npm run dist:win
```

验证签名是否生效：

```powershell
Get-AuthenticodeSignature .\release\TermDeck-Setup-0.4.0.exe | Select-Object Status, SignerCertificate
```

`Status` 应该是 `Valid`，发布者不再是「未知发布者」。带签名的构建还会顺带消掉
SmartScreen 对**每一个**新版本的重复提示。

## 四、还可以做的

- **提交误报**：如果某个杀软对新版本报了毒（未签名 Electron 应用偶发），在
  <https://www.microsoft.com/en-us/wdsi/filesubmission> 提交文件，选「软件开发者」，
  一般几天内会加白名单。
- **发布页写清校验值**：每个版本的三个文件都附 SHA256，用户能自证拿到的是构建出来的
  那份（`Get-FileHash` 一比对即可）。
