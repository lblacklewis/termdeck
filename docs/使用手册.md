# TermDeck 使用手册

一个 Windows / macOS 上的 SSH 终端管理器：把常用主机、分组、密钥和密码放在一处，分屏开终端，
顺手带上文件传输、命令补全和一套能看清的界面。本手册按「你会怎么用它」组织，功能都写
最短的使用路径；背后的设计取舍在 `README.md` 里。

## 1. 第一次启动

第一次运行会先问四件事，**全部可以以后再改**：

| 选项 | 说明 |
| --- | --- |
| 语言 | English / 简体中文，选完整个界面立即切换 |
| 配色 | 13 套主题，选一个就立刻套上预览 |
| 终端字体 | 自带 Roboto Mono 与 JetBrains Mono，不依赖系统装没装 |
| 数据保存位置 | 默认在用户目录；可以换到同步盘、移动硬盘等位置 |

点「开始使用」写入并记下「已看过」，之后不再出现。老版本升级上来的第一次也会看一次
（数据目录必须在写入任何东西**之前**选）。

> 从旧版本升级：主机、分组、会话、密码、主题、快捷键都会保留。

## 2. 界面速览

```
┌────┬──────────────┬─────────────────────────────────────┐
│轨道│  抽屉（列表） │  主区：终端分屏 / 各页面            │
│ ▚  │  会话树       │  ┌────────┬─────────┐               │
│ ⣿  │  历史         │  │ 窗格   │  窗格   │              │
│ ⛨  │  SFTP         │  └────────┴─────────┘               │
│ ⋯  │               │                                     │
└────┴──────────────┴─────────────────────────────────────┘
```

- **轨道**（最左，图标栏）：切换主区。依次是终端、主机、已知主机、代码片段、日志，最后是设置。
- **抽屉**（轨道右侧那一列）：终端页里显示会话树 / 打开的会话 / 历史 / SFTP；切到别的页面时显示该页面的列表。
- **主区**：终端分屏，或者当前页面的内容。
- 底部有一条状态栏；出现提醒（比如休息）时会用不打断操作的横条提示。

轨道左下角的小开关可以把抽屉收成图标条，`Ctrl+B` 同效；**再次点击当前页面的图标**也会收起 / 展开抽屉。

## 3. 连接主机

**快速连接**：`Ctrl+T` 打开新建连接窗口，填主机、端口、用户名，认证方式三选一：

- **密码**：勾选「记住密码」后会加密保存（见下面的凭据说明）；
- **密钥文件**：选 `.pem` / `.ppk` 之类的私钥；
- **ssh-agent**：用系统里已经在跑的 agent。

**保存成主机**：填好后点保存，它会出现在左侧会话树里，双击即可连接。

**批量添加**（主机页）：把多行 `用户名@主机:端口` 一次粘进去，自动去重，共用同一个密码。

**分组**：主机页可以新建分组、把主机拖进分组、嵌套子分组。删除还有内容的组会先问一句，并写清里面有几台主机、几个子分组。

**主机密钥**：第一次连某台机器会显示指纹并要求确认；设置 → 主机密钥 里可以选「总是询问 / 首次信任 / 全部信任」。指纹变过时会明确警告「已改变」。

**视图**：主机页支持卡片 / 列表两种排法，切换后**切页和重启都记得**。

## 4. 终端操作

**分屏**：把标签拖到窗格的**边缘**（左/右/上/下）就分出新窗格；拖到另一个窗格**中心**则合并成标签组。拖动过程中不会逐帧重排，所以不卡。窗格之间的分隔条可以拖动调整大小。

**标签**：右键标签有菜单 —— **排列窗格…**（见下）、复制标签名、复制全部输出、保存输出到文件、显示/隐藏时间戳、**重载 / 重连**（丢了连接时用它，会回退到保存的主机重连）、把这条连接再开一个（同一主机新标签）。

**会话结束后**：窗格里会显示「Session ended」横幅。此时：

- 按 **`Ctrl+D`** 直接关掉这个窗格（活着的 shell 里 `Ctrl+D` 仍然是 EOF，不会被抢走）；
- 或者右键标签 → 重载 / 重连。

**复制粘贴**：选中即复制；`Ctrl+Shift+C` / `Ctrl+Shift+V`。右键窗格 = 粘贴剪贴板。

- **双击**选一个词，**冒号、逗号、分号算分隔符** —— 双击 `key` 得到 `key`，不会把后面那个 `:` 也带走。
- **三击**选整行，复制时**自动带一个换行**，可以直接粘成一行。
- 普通拖选复制**不会**多出空行：换行只跟着"三击选整行"那一次。

**字体大小**：`Ctrl`+`=` / `Ctrl`+`-` **只改终端里的字**（8–32px），界面其余部分不动。

**光标**：设置 → 终端 里可选空心方框（默认）、实心块、竖条、下划线。

**一键排列所有窗格**：`Ctrl+Shift+T`，或右键任意标签 → **排列窗格…**。弹出框里默认勾选**所有**窗格（可以取消其中几个），然后选排列方式：

| 方式 | 效果 |
| --- | --- |
| 瓷砖排列 | 自动分成接近方形的网格（4 个窗格 = 2 × 2） |
| 竖屏分割 | 左右并排，每列占满高度 |
| 横屏分割 | 上下排列，每行占满宽度 |

排列只是移动窗格，**不会断开任何会话**；分完各个窗格大小相等。按钮上会写清要排列几个窗格。

**其他**：`Ctrl+Shift+B` 把输入**广播**到所有可见窗格（多台机器同时执行同样的命令）；专注模式（`F11`）只留窗格。

## 5. 命令历史与补全

**补全**：在命令行里开始输入，就会弹出你**跑过的命令**里以这段文字开头的那些。

| 键 | 作用 |
| --- | --- |
| `↑` / `↓` | 在候选里移动 |
| `Enter` 或 `Tab` | 把选中的命令**填进命令行**，不会执行 |
| `Esc` | 关掉候选 |

候选在光标上方，弹出时会显示已输入部分（暗）+ 将要补上的部分（亮）。**弹出层没打开时
`↑`/`↓` 完全不管**，shell 自己的历史照旧能用。

补全只写「剩下的部分」：输入 `git sta` 选中 `git status --short`，实际只发送 `tus --short`。

**候选范围**：**所有 session 共用一份历史** —— 想找的那条命令，常常是在另一个窗格里跑过的。

**什么不会被记录**：

- 以**空格开头**的行（shell 的「别记我」约定，也是打错的密码最容易被写进明文文件的方式）；
- 空行、上下相邻的重复、超过 240 字符的行；
- 总量上限 400 条，重复命令会置顶而不是攒一堆。

**历史面板**：抽屉里的「历史」按 session 分开看（每个 session 一个文件，保留 7 天），
和补全用的共用列表是两回事 —— 前者是「这台机器上我跑过什么」，后者是「我最近跑过什么」。

## 6. 文件传输（SFTP）

抽屉 → **SFTP**：连接成功后列出远端目录，可以进目录、下载、上传、新建、重命名、删除。

**拖拽上传**：把文件从资源管理器直接**拖到 SFTP 面板上**——面板会高亮并提示"松手即上传到这个目录"，
松手就传。一次拖多个会按顺序逐个传；读不出文件路径的拖放内容会明确说一声，不会静默失败。

**看进度**：任何上传/下载开始时，**快捷指令栏上方会出现一条传输栏**（自己出现，不用去找）：

- 收起时也读得出在传什么：文件名、方向、百分比、总速度；
- 点 ⌄ 展开是完整列表：已传/总量、百分比、实时速度、剩余时间、**取消**；
- 全部传完自动收起，已完成的记录会**保留**，点 ⌃ 随时再看；
- **✕ 只是隐藏这条栏**，传输继续跑，之后有新任务会把它重新带回来；
- **⌫ 一键清除**已完成的记录（进行中的不会删）。清空后传输栏自动消失。

也可以按 `Ctrl+Shift+J` 打开独立的传输窗口，内容与展开的传输栏一致。

**速度**：下载和上传都是**多个块同时在传**，不再"一次一个块、等一个来回"，所以高延迟的远端也不再是
几百 KB/s。取消是真的取消：不再申请新块，不会出现"点了取消还在往下拉"。

## 7. 代码片段

轨道 → **代码片段**：常用的长命令存成片段，按标签搜索。终端页底部有**片段条**
（`Ctrl+Shift+S` 开关），点一下就把它写进当前窗格。

**颜色**：给一条片段挑个颜色，它会显示成**按钮下沿的一条色带**，长得差不多的命令一眼就能分开。
编辑器里八个常用色一格一个，右边是系统取色器，也可以选"不设颜色"。

**分组**：片段条左侧只有**一个按钮**，默认显示「全部」。点开是一张勾选清单（每组一行、带数量）：

- **可多选** —— 勾两个分组就是两组的并集，按钮上会写出勾了哪些；
- 全都不勾 = 全部；
- 分组之间搬片段用**右键菜单的「移到 <分组>」**（"未分组"永远是一个可选目标）。

## 8. 已知主机

轨道 → **已知主机**：列出 `known_hosts` 里的每一条，带主机名、密钥类型、指纹。

- **过滤**：顶部搜索框按主机名 / 类型 / 指纹过滤；
- **单条忘记**：行尾「忘记」→ 确认；
- **批量忘记**：每行有复选框，表头可全选，选中后点「忘记选中的（N）」并确认 —— 机器重装、
  换过密钥的时候一次清一批；
- 选择集跟着过滤条件走：「已选 2」永远等于你**看得见**的那两行。

被 OpenSSH hash 过的条目会显示为「(hashed entry)」，这是正常的：主机名在那个格式里真的
还原不出来。删除是按行定位的，所以 hashed 条目也能删。

## 9. 主机配置的搬移与备份

**加密导出 / 导入**（`.tdshare` 文件）：

- 主机页工具栏的 **Export / Import**，或 **设置 → 凭据 → 主机备份**（同一个对话框）；
- 导出把整棵树（分组、主机、标签、密码）打包成一个文件，口令自己定；
- 文件是**先 gzip 再 AES-256-GCM 加密**的（密钥用 scrypt 从口令派生），地址、名字、密码都读不出来；
- 导入按「用户名 + 主机 + 端口」去重、同名分组复用、密码按本机新 id 重新封装 ——
  同一个文件导入两次不会翻倍。

适合把一个机群交给同事，或者换机器时搬过去。

## 10. 外观：主题、字体、缩放、语言

设置 → **外观**：

- **主题**：13 套，含浅色（Termius Light、Slate Light、Paper、粉色 **Blossom**、亮紫 **Lavender**）和深色若干。选中即预览，不保存关掉就还原。
- **语言**：English / 简体中文，立即生效。
- **界面缩放**：80%–150%，`Ctrl`+`Shift`+`=` / `Ctrl`+`Shift`+`-` 也能调；整个界面（轨道、抽屉、对话框、间距）一起缩放。

**终端字体大小**是另一回事：`Ctrl`+`=` / `-`，只影响窗格里的文字，在 设置 → 终端 里也能选
（8–32px，另有行高）。

## 12. 工作习惯类功能

- **番茄循环**：设置 → 健康提醒 里开启，工作一段自动进入休息，休息结束回到工作。抽屉底部有个小胶囊显示当前处于哪一半、还剩多久。
- **休息提醒**：到点用**不打断操作**的横条提示（并等终端空闲才出现），可以选择休息、休息并锁屏、稍后提醒。
- **锁屏**（`Ctrl` + `Alt` + `L`）：可以设密码，挡住屏幕但会话继续跑。
- **专注模式**（`F11`）：只留窗格。
- **退出确认**：点 X / `Alt`+`F4` 时会写清要关掉几个连接，确认后才退出。

## 14. 数据存在哪、怎么迁移

默认在系统给的应用数据目录里：Windows 是 `%APPDATA%\TermDeck\`，macOS 是
`~/Library/Application Support/TermDeck/`（准确路径欢迎页与设置里会直接显示）。里面是设置、
布局、会话、密码、历史。改动位置：

- **欢迎页**里选（推荐：那时还没有写入任何东西）；
- 或者 **设置 → 凭据 → 数据保存位置**。

改的时候会把现有文件**复制**到新目录再重启（复制而不是移动：移动到一半就是数据丢失）。
真正的「指针」放在系统用户目录里，所以即使新目录被删掉或移动硬盘拔了，应用也会安全地
退回默认位置。

## 15. 常见问题

**运行时报「Windows 已保护你的电脑」**
不是报毒，是 SmartScreen 对**未签名 + 从互联网下载**的文件的默认拦截。处理方式：

1. 弹窗里 **更多信息 → 仍要运行**（一次性）；
2. 或者先解除下载标记，之后不再问：右键文件 → 属性 → 勾「解除锁定」，或
   `Unblock-File .\TermDeck-<版本>-x64.exe`。**解压前先对 zip 解除锁定最省事**；
3. 核对 SHA256（发布页附了校验值）：`Get-FileHash .\TermDeck-<版本>-x64.exe -Algorithm SHA256`。

单文件便携版每次启动都会解压到临时目录，最容易反复触发 —— 给人分发时优先给 **zip** 或
**安装版**。要彻底不再提示需要代码签名证书，细节见 `docs/安装与信任.md`。

**macOS 上打开时报「无法验证开发者」／「已损坏」**
同样不是报毒：mac 版没有代码签名也没有公证，Gatekeeper 默认不让它第一次运行。两种处理：

1. 在「访达」里 **右键（或按住 Control 点击）TermDeck.app → 打开**，弹窗里再点一次「打开」；
2. 或者解除隔离标记，之后就能正常双击：

   ```bash
   xattr -dr com.apple.quarantine /Applications/TermDeck.app
   ```

另外：mac 上密码是用**钥匙串**加密保存的，应用被移动过（或换了签名）之后，之前存的密码
可能取不回来，需要重新输一次 —— 这是系统行为，不是数据丢了。

**本地 shell 里 `brew` 装的命令找不到**（macOS）
正常情况不用管：应用会把 `/opt/homebrew/bin` 与 `/usr/local/bin` 加进 `PATH`。
如果还是找不到，先确认它是 brew 装的（`ls /opt/homebrew/bin`），再检查是不是用了
`$SHELL` 之外的 shell（设置里可以指定）。

**连不上**
先在终端里试 `ssh 用户@主机`，能通说明网络没问题；再看 设置 → 主机密钥 是不是停在询问上、
密码是否过期、以及是否用了需要交互的键盘认证（本版本支持密码 / 密钥文件 / agent 三种）。

**「主机密钥已改变」**
可能是机器重装或换了密钥，也可能是被中间人。确认无误后到 **已知主机** 页把旧指纹忘记，
下次连接重新接受。

**忘了保存的密码**
密码是加密存的，没有「找回」；到主机页编辑该会话重新输入一次即可。

**想恢复成刚下载的状态**
退出应用，删掉 `%APPDATA%\TermDeck\`（先备份一份），再启动 —— 会重新走一次欢迎页。

**日志**
轨道 → 日志显示本次运行期间的事件（连接、断开之类），关掉应用就没了，不落盘。
