# TermDeck v1.1.0

本地终端之外，SSH、Telnet、串口三种登录方式；三个新工具页；以及一个一直在偷偷开新窗口的重连 bug。

v1.0.0 之后 17 次提交。这一版的重点是**把终端工具伸手能够到的地方补齐**：管串口和 telnet 设备、
把只有内网能到的服务捅出来、手边没有 curl 的时候发一个 REST 请求、看一眼对象存储里到底有什么。

## 新增

**连接方式：SSH / Telnet / 串口**（主机编辑器 → 连接方式）

- **Telnet**：零依赖自己实现的协商（只应答窗口大小与终端类型，其余一律拒绝）。UTF-8 流式解码，
  一个中文字跨 TCP 段也不会烂；行尾按终端习惯归一。
- **串口**：设备路径 + 波特率（9600 ~ 115200，也接受非列表里的值）/ 数据位 / 校验 / 停止位。
  走可选的 `serialport`；这一版带上了它。
- 旧的主机条目不受影响：没有连接方式字段的一律还是 SSH。

**登录后自动执行命令**（同一张表单的底部）

连上之后按顺序把命令敲进去，首条等 900 ms，之后每条 +400 ms —— 足够让 motd 和各家的
shell 提示符就位，又不至于让你盯着屏幕等。SSH / Telnet / 串口都能用。

**隧道（本地端口转发）** — 左边栏 `⇄ Tunnels`

把本机的一个端口，经一台 SSH 主机，接到**那台主机能访问到**的地址。典型用途是够后台的数据库
或管理界面。

- 每条隧道**独占一条 SSH 连接**，所以关掉终端窗格不会顺手杀掉转发，停掉一条也不会影响别的。
- 认证参数直接复用你连那台主机用的那一套（私钥、agent、主机密钥校验），没有第二套规则。
- 只有本机能用转发（监听 127.0.0.1）：绑到 `0.0.0.0` 等于把内网服务发布到整个局域网，
  那该是一个明确的决定，不该是默认值。
- **启动时不自动重连** —— 开机悄悄挂起一条生产链路，是这个功能最容易造成的意外。
- 改动一条正在运行的隧道的指向会把它停掉（监听器和通道是按旧参数建的），表单会先告诉你。

**REST 工具（内置模板）** — 左边栏 `⇢ REST`

方法 / URL / 请求头 / 请求体，发出去看状态码、耗时、大小、响应头、响应体（JSON 自动美化）。

- 请求**从应用主进程发出**，所以在页面里被 CORS 挡住的本机服务（Ollama、Elasticsearch、
  健康检查）这里能直接调。
- 内置模板：Ollama 列模型 / Ollama 生成 / Elasticsearch 集群健康 / Prometheus 即时查询 /
  通用健康检查 / GitHub 仓库 / JSONPlaceholder。
- 草稿与收藏都会留下，关掉窗口再打开还在。
- 响应体可搜索（按行过滤 + 命中计数），超过 400 行先折叠。
- 每个请求可单独设超时；**自签证书必须每次明确勾选**（默认关）。
- **Copy as cURL**：在这里调通之后要拿到别处复现，一键复制成一条可直接粘贴的命令。
- Format JSON 一键美化请求体。

**S3 工具** — 左边栏 `☁ S3`

连接（端点 / 区域 / AK / SK / path-style）、列桶、按目录浏览对象、看内容、改内容写回、删除。

- 支持 path-style 寻址：MinIO、Ceph 这类网关和用 IP 直连的场景只能用它（默认开）。
- **Secret key 只留在内存里，不落盘**。仓库里其它连接文件存的是"点一下就能重连"的主机信息；
  云端密钥能开的通常比你在看的那个桶多得多，所以默认每次会话重输。
- 不引 AWS SDK：SigV4 是手写的，用 AWS 官方两条工作示例**逐字符**对拍，
  并由 mock 服务端从收到的字节重算签名复核。

## 改进

- **SFTP 面板的路径可以直接输入**：以前只能一层层点。现在输入路径回车跳转，Esc 取消。
- 主机树与主机页会正确显示 telnet / 串口的目标（`host:23`、`COM3 · 115200`），
  而不是把串口硬套成 `user@host:22`。

## 修复

- **会话断掉后再连同一台主机，现在在原窗格里重连**，不再多开一个标签。以前每次重连都会多留
  一个死窗格。仍然活着的窗格不会被顶掉 —— 想同时连两台请用「复制连接」。
- 编辑一条正在运行的隧道只改定义、监听器还按旧参数转发（界面显示 9090、实际听 8080）。
  现在改指向会先停掉它。
- S3 预览里改过的内容会带到下一个对象上，点"写回"会把 A 的内容写到 B 的 key。现在切换对象
  即清空草稿，写回成功后重新读取该对象。
- S3「保留连接」每点一次就多一条（去重比的是去掉 scheme 的名字和带 scheme 的端点）。

## 安装

| 文件 | 说明 |
| --- | --- |
| `TermDeck-Setup-1.1.0.exe` | 安装版（可选安装目录，快捷方式） |
| `TermDeck-1.1.0-x64.exe` | 便携版单文件，双击即用 |
| `TermDeck-1.1.0-win-x64-portable.zip` | 解压即用的目录版 |

**首次运行会弹「Windows 已保护你的电脑」** —— 这是 SmartScreen 对**未签名**且**从互联网下载**的
文件的默认拦截，不是报毒。三种处理方式：

- 弹窗里点 **更多信息 → 仍要运行**（一次性）；
- 先解除下载标记就不再追问：右键文件 → **属性** → 勾选 **解除锁定**，或者
  `Unblock-File .\TermDeck-1.1.0-x64.exe`。**解压前**先对 zip 解除锁定最省事（Windows 会把标记
  传给解压出来的文件）；
- 核对 SHA256（发布页附了三个文件的校验值）：

  ```powershell
  Get-FileHash .\TermDeck-1.1.0-x64.exe -Algorithm SHA256
  ```
