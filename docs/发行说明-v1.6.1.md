# TermDeck v1.6.1

## 修复

**重连页面按 `Ctrl+R` 没反应**

`Ctrl+R` 本来只对"会话结束"的那一块覆盖层生效。但还有**另一种重连页面**：从上次布局里恢复出来、尚未连接的窗格
（「这个窗格是从上次布局恢复的，不会自动重连」那一个）。在那个页面上按 `Ctrl+R`，走的是"重新打开这个窗格原来
那个会话"的路子 —— 而它从来没有过会话，于是去找一个不存在的会话 id，什么也没发生，还会弹一句
"…不再保存，无法恢复"。

现在这两种页面分别走各自该走的路：

- 会话结束 → 重新打开这个窗格原来的连接（保持同一个 session id，历史都在）；
- 从布局恢复、尚未连接 → 通过它**保存的主机**重新连（和那个页面上的按钮完全同一条路）。

## 新增

**两个重连页面都直接写出快捷键**

页面上的提示现在是 `或按 Ctrl + R 重连。`，**读的是当前绑定而不是写死的文字** —— 你在设置里改了键，页面上显示
的就是改后的键，不会继续骗你说 Ctrl+R。

## 验证

完整闸门 `npm run verify`：41 套件全过。

- `smoke:layout` 20 → **21 条**：恢复出来的窗格上显示的重连键**等于设置里真正绑定的键**；**按这个键**能把该窗格
  连起来（占位页面消失、pane 数不变、live +1、且不弹"不再保存"）。这条断言在修复前必然失败。
- `smoke:reconnect` 30 → **32 条**：会话结束的覆盖层会写出快捷键，且写出的就是绑定的那个键。
  （"Ctrl+R 能重连已结束的会话""在活着的 shell 里 Ctrl+R 不抢键"两条本来就有，继续覆盖。）
