# TermDeck v1.4.1

## 修复

**双击选词不再把后面的 `:` 带上**

以前双击 `key` 会选中 `key:` —— 冒号被复制到剪贴板，而那正是你不需要的东西。xterm 默认的分词符只有
括号和引号，冒号不在里面，所以它算作单词的一部分。现在冒号和逗号、分号一起算作分隔符：

- `key: value` 双击 `key` 得到 `key`；
- `10.0.0.1:22` 双击得到地址本身。

（`=` 故意没有加进去：它更多是 token 的一部分 —— `--flag=value`、`KEY=value` —— 而不是跟在词后面。）
代价是 `http://example.com` 这种含冒号的地址双击会断在冒号处，如果你更希望保住 URL，说一声我把它拿掉。

**三击选整行，复制出来带换行**

三击已经会选中整行，但复制出来的文本没有换行 —— 粘到别处就会和后面的内容粘成一行。现在：

- 三击选中的那一行，复制时**自动补一个换行**；
- 只在三击之后的那次复制上生效（2 秒窗口，且再点一下就清掉），普通拖选复制不会凭空多一个空行；
- 复制走的是两条路：选中即复制（copy-on-select）和 `Ctrl+Shift+C`，两条都按同一个规则。

## 验证

完整闸门 `npm run verify`：41 套件全过。`smoke:features` 100 → **104 条**：双击选中的是 `alpha`
而不是 `alpha:`、三击选中整行、剪贴板里的那一行以换行结尾、之后普通选词复制不带换行。
