# TermDeck v1.4.2

## 修复

**主机标签：敲完直接点保存，标签不再丢**

标签输入框只在**回车或逗号**时才把内容变成一个标签。于是最常见的操作顺序 —— 敲上 `prod`，接着就去点
「保存」—— 会把刚敲的内容悄悄丢掉：保存成功，标签没了，看起来就是"标签保存不上"。

现在提交表单时会把输入框里还留着的内容一并算作标签（两种保存路径都算：单条保存和批量导入，折叠在
同一处，不会各说各话）。

- 输入 `prod` 直接点保存 → 标签就在。
- 回车/逗号的老行为不变；重复的标签仍然只留一个。

## 验证

完整闸门 `npm run verify`：41 套件全过。`smoke:hosts` 56 → **59 条**，其中新增的一条专门走这条路：
打开编辑器 → 输入标签但**不按回车** → 直接保存 → 主机行上必须出现该标签。它此前会失败，也就是这次
修的那个 bug。
