# TermDeck v1.5.2

## 修复

**分屏里另一侧的标签页名字，几乎看不见**

dockview 自带的 abyss 主题把标签文字画成白色 50%，而在**没有焦点的那一组**里画成白色 **25%**。后者叠在我们
的背景上只有 **2.25:1** —— 名字是在那里，但看不见。分屏之后，另一半的标签名就是这么一副样子。

现在标签文字用本主题的墨色：当前标签用正文色，其余用次级墨色（实测 **6.84:1**，WCAG AA 要求 4.5:1）。

**同时让"当前是哪个标签"不只靠亮度**

文字都能看清之后，光靠亮一点来区分"当前标签"就不够明显了，所以当前标签**下沿加一条 2px 的强调色细线**。
不用伪元素，是因为 dockview 已经把 `.dv-tab:focus-visible::after` 用在焦点框上了 —— 抢它会把键盘焦点提示
弄坏。

（问题出在变量被声明在**每个分组**上，不是只在 dockview 根节点上；只覆盖根节点时，每个标签读到的仍是分组
自己那份 25% 白。这条写进交接文档了。）

## 验证

完整闸门 `npm run verify`：41 套件全过。`smoke:layout` 18 → **20 条**，新增的两条在**分屏之后**测量
（那正是问题出现的状态）：

- 每个标签名对自己所在标签条背景的对比度 ≥ **4.5:1** —— 修复前这条会失败并报出 `2.25:1
  rgba(255,255,255,0.25)`，即这个 bug 本身；
- 当前标签是其中最亮的那个（分开比较，避免"都合格"掩盖"分不出来"）。
