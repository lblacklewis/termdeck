# TermDeck v2.2.0

TermDeck 是一个 SSH / SFTP 终端客户端：可拖拽、可停靠的终端窗格，加上会话树、主机批量管理、
端口转发、对象存储与 REST 工具页。Windows 与 macOS 都有构建。

**v2.2.0 是给 macOS 的一次补课**：v2.1.0 让它在 Mac 上能跑起来，但快捷键是把 Windows 的
`Ctrl` 机械换成 `Cmd` 得来的。这一版按 Mac 用户**实际的**习惯重做了键位与几个操作习惯。
**Windows 侧没有功能变化** —— 默认键位、剪贴板默认值、菜单都逐条断言过没变；唯一的细节是：
焦点在输入框里时，复制/粘贴快捷键不再被应用截走，而是交给系统处理（以前那一下会被吃掉）。

## macOS：这次按 Mac 的习惯改了键位

| 作用 | 之前（v2.1.0） | 现在 | 为什么 |
| --- | --- | --- | --- |
| 复制 / 粘贴 | `Cmd`+`Shift`+`C` / `V` | **`Cmd`+`C` / `Cmd`+`V`** | Mac 上的复制粘贴就是这两个键；`Ctrl`+`C` 仍然是发给 shell 的 SIGINT |
| 全屏 | `F11` | **`Ctrl`+`Cmd`+`F`** | Mac 没有 `F11` 这个习惯，全系统都是 `Ctrl`+`Cmd`+`F` |
| 下一个 / 上一个标签 | `Ctrl`+`Tab` | **`Cmd`+`Shift`+`]` / `[`** | Terminal.app / iTerm2 的换标签手势 |
| 跳到第 N 个会话 | `Option`+数字 | **`Cmd`+数字** | `Option`+数字在 Mac 的输入框里是打符号；`Cmd`+数字才是"去第 N 个标签" |
| 上一个 / 下一个会话 | `Option`+`[` / `]` | **`Cmd`+`Alt`+`←` / `→`** | iTerm2 的换标签键位 |
| 打开设置 | 键位 `Cmd`+`,` | **应用菜单「TermDeck → 设置…」** | Mac 用户就是在菜单里找设置；键位交给菜单，两边不再抢同一个键 |
| 退出 | 键位 `Cmd`+`Shift`+`Q` | **应用菜单「TermDeck → 退出」（`Cmd`+`Q`）** | 同上，`Cmd`+`Q` 是每个 Mac 应用的退出键 |
| 锁屏 | `Cmd`+`Alt`+`L` | **`Ctrl`+`Cmd`+`L`** | 与 Windows 的 `Ctrl`+`Alt`+`L` 对位，同时避开系统自己的 `Ctrl`+`Cmd`+`Q` |
| 关闭已结束的窗格 | `Cmd`+`D` | **不再单独绑定** | `Cmd`+`W` 本来就能关任何窗格；而 `Cmd`+`D` 在 Mac 终端里是"分屏" |

操作习惯也按平台分开了：

- **不再"选中即复制"**（Mac）：和 Terminal.app / iTerm2 一样，选中之后按 `Cmd`+`C`。
  Windows 上保持原来的"选中即复制"。
- **中键粘贴默认关闭**（Mac 没有中键）；右键粘贴两个平台都保留。
- **输入框里的 `Cmd`+`C` / `Cmd`+`V` 归系统**：焦点在设置、对话框的输入框里时，这两个键交给
  系统处理（xterm 自己的复制粘贴照旧），两边不会互相抢。
- 界面上出现快捷键的地方（抽屉底部的"新建连接"、重连提示、设置里的快捷键列表）现在都**按平台
  显示**：Mac 上写 `Cmd`，Windows 上写 `Ctrl`，你改过键位的话显示的就是你改后的键。

**从 v2.1.0 升上来，旧键位会自动迁移**：只改"恰好等于旧默认值"的那些（例如 `Cmd`+`Shift`+`C`
→ `Cmd`+`C`、`F11` → `Ctrl`+`Cmd`+`F`），你自己设过的组合原样保留。剪贴板那两项是存盘优先，
已经运行过 v2.1.0 的机器会保留当时存下的值（想改成新默认，去 设置 → 剪贴板 里勾一下即可）。

## CI 也修了一处

v2.1.0 的 mac 构建**没能出产物**：探针在真机 macOS 上发现"本地 shell / 字体 / 键位"里有一项不对，
而当时探针和打包在同一个 job 里，探针一红，打包就被跳过了。现在两件事**分成两个独立 job**：
打包照常出 dmg / zip，探针的红绿在 Actions 页面上单独可见，失败的检查项还会以注解列出来。
字体枚举那条也修了（`system_profiler` 给足了超时、并且用绝对路径调用）。

## 已知边界（写在明处）

- **macOS 产物未签名、未公证**：第一次打开要右键「打开」，或
  `xattr -dr com.apple.quarantine /Applications/TermDeck.app`；app 换过位置之后，钥匙串里
  已存的密码可能要重输一次。
- macOS 的真机人工验收清单在 [docs/交接-macOS适配.md](交接-macOS适配.md) 第 9 节
  （CI 产物怎么取、怎么过 Gatekeeper、`npm run smoke:mac`、打包版自检、串口与钥匙串）。
- **S3 页与端口转发页仍是英文界面**；`~/.ssh/config` 导入还没做。
- Windows 只提供 x64 构建。

## 校验

```powershell
Get-FileHash -Algorithm SHA256 .\TermDeck-Setup-2.2.0.exe
```

```bash
shasum -a 256 TermDeck-2.2.0-arm64.dmg
```

和附件里对应的 `SHA256SUMS-*.txt` 对一下即可。
