# TermDeck v2.3.0

TermDeck 是一个 SSH / SFTP 终端客户端：可拖拽、可停靠的终端窗格，加上会话树、主机批量管理、
端口转发、对象存储与 REST 工具页。Windows 与 macOS 都有构建。

**v2.3.0 是 S3 工具页的一次重排**：原来的页面把表单、桶列表、对象列表、预览自上而下堆成一列，
宽窗口下中间一大片空白；这一版改成**三栏工作区**，并给 S3 加了**访问历史**——去过哪些
bucket/文件夹记下来，回头一点就回到原地。Windows 侧其它功能没有任何变化。

## S3 页：三栏工作区

| 位置 | 放什么 |
| --- | --- |
| **左栏** | 访问历史（如果有）+ 桶与对象的**树**：桶是根，文件夹和文件按层级缩进挂在自己的桶下面 |
| **中栏** | **文件内容**，占整页最宽的一列、撑满可用高度；没打开文件时显示提示，不再是一片空白 |
| **右栏** | **元数据**：打开的对象看 key / 桶 / 大小 / 类型 / 修改时间 / 是否截断；没打开时看当前连接概要 |

窗口宽度不够三栏时（约 1080px 以下），三个区域按同样顺序上下堆叠，内容不丢。
上传/下载的结果提示也挪到了右栏，不再插在列表中间。

## S3 页：访问历史

- **每真正列出一个文件夹，就记一条**：端点、区域、Access key、bucket、前缀、时间。
  同一个地方反复去只留一条，最新的排最前，最多 20 条。
- **历史里没有秘密**：secret key 从来不进历史（也不进存盘的草稿）——历史能带你回到
  那个地方，但不能替你开门。
- **点一条历史**：
  - 还连着同一个端点、密钥也在内存里 → 直接跳到那个 bucket/文件夹；
  - 不是同一个端点 → 表单自动填好（密钥留空等你输入），连接成功后**直接落进**当时那个文件夹。
- 端点、区域、Access key 的表单草稿现在随访问一起存盘，重开应用不用重新输。

## 其它

- 快捷键、菜单、主题、终端行为与 v2.2.0 完全一致；这一版只动了 S3 工具页。
- 探针从 30 条扩到 **51 条**：树的形状、历史的去重/上限/无秘密、三栏的几何位置，
  都是"旧实现必然失败"的断言（在真窗口里量 DOM 几何，不是看有没有报错）。

## 已知边界（写在明处）

- **macOS 产物未签名、未公证**：第一次打开要右键「打开」，或
  `xattr -dr com.apple.quarantine /Applications/TermDeck.app`。
- **S3 页与端口转发页仍是英文界面**；`~/.ssh/config` 导入还没做。
- S3 的历史保存在本机 `s3.json`（数据目录见 使用手册 §14），跟着「数据目录」一起迁移。
- Windows 只提供 x64 构建。

## 校验

```powershell
Get-FileHash -Algorithm SHA256 .\TermDeck-Setup-2.3.0.exe
```

```bash
shasum -a 256 TermDeck-2.3.0-arm64.dmg
```

和附件里对应的 `SHA256SUMS-*.txt` 对一下即可。
