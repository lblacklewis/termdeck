# TermDeck v2.4.0

TermDeck 是一个 SSH / SFTP 终端客户端：可拖拽、可停靠的终端窗格，加上会话树、主机批量管理、
端口转发、对象存储与 REST 工具页。Windows 与 macOS 都有构建。

**v2.4.0 带来两件事**：一是新功能 —— **从本机 `~/.ssh/config` 一键导入主机**，机器多的配置
不用再一台一台抄；二是把上一版之后修的三处问题正式发出去（切换窗格键盘跟随、REST 请求头
单引号与页签、请求体高度），其中第一处正是有用户遇到的「保存的条目缺请求头」的根因。

## 从 `~/.ssh/config` 导入

主机页工具栏新增 **「SSH config…」** 按钮。点开后 TermDeck 读取本机的 OpenSSH 配置
（`~/.ssh/config`），把里面每一台**具体的机器**列成清单：勾选想要的、选一个目标分组、
点导入，一次落盘。

- **各归其位**：`HostName` / `User` / `Port` / `IdentityFile` 分别变成地址、用户名、端口、
  私钥路径；没有 `HostName` 的条目用别名本身当地址。
- **模式块照 OpenSSH 的规矩继承**：`Host *`、`Host web-*` 这类块不是机器，但它们设置的
  `User` / `IdentityFile` 会按「先到先得」规则补给命中的主机 —— 和你平时
  `ssh 别名` 连上去的行为一致；`!` 排除同样生效。
- **`Include` 支持**：字面路径、绝对路径、`~` 开头都读（相对路径按 `~/.ssh` 解析）；
  引用缺失的文件直接跳过，不会让整个导入失败。
- **已存在的不重复进**：用户名、主机、端口都相同的主机会列出来但**不勾选**，标着
  「已存在」；想强制再导一份可以手动勾上，但导入时仍会被跳过 —— 两次导入不会翻倍。
- **凭据怎么办**：`IdentityFile` 变成私钥认证（路径已展开 `~`）；没有私钥的条目按密码
  认证导入，第一次连接时会像手工新建的主机一样询问密码。
- **`ProxyJump` / `ProxyCommand` 抄进备注**：TermDeck 目前不做跳板链，所以不静默丢弃，
  而是在备注里注明「未生效」，避免导出来的主机连不上却查不到原因。
- **不读的就不猜**：`Match` 块依赖运行时上下文，离线导入判断不了，整个忽略。

## 一起发出去的三处修复

这三处在 v2.3.0 之后就已修好，本版是它们第一次进入安装包：

- **切换窗格后键盘直接跟着走**：点标签、点侧栏会话行、快捷键切窗格，输入焦点立刻落到
  新窗格的终端上，不用再点一下才能打字（正在输入框里打字时不受打扰）。
- **REST 请求头认识单引号 + 页签带着数据切换**：从控制台复制来的
  `{'Content-Type': 'application/json'}` 这类对象字面量现在能正确读成请求头；
  「逐条 / JSON」两个页签来回切，写了一半的内容不再丢失。
  —— 之前 v2.3.0 里单引号请求头被当作格式错误拒收，**保存下来的条目因此没有请求头**，
  选回来也没有；升级到本版即消失。请求体那一侧一直都在保存。
- **REST 请求体的高度固定住**：拖出来的高度会被记住，切去别的工具页再回来、重启应用
  都不再弹回默认高度。

## 其它

- 主机导入探针从零新增 **36 条**：解析语义（通配符继承、`!` 排除、`Include`、`Key=Value`
  写法）与真实界面（对话框、去重勾选、分组落位、二次导入不翻倍、配置文件缺失时的提示），
  在未实现这些功能的旧代码上实测**退出码 1**。
- 快捷键、菜单、主题、终端行为与 v2.3.0 一致。

## 已知边界（写在明处）

- **macOS 产物未签名、未公证**：第一次打开要右键「打开」，或
  `xattr -dr com.apple.quarantine /Applications/TermDeck.app`。
- **S3 页与端口转发页仍是英文界面**。
- `~/.ssh/config` 导入不支持 `Include` 通配（`config.d/*.conf` 这类不展开）、不支持
  `Match` 条件块；跳板链（`ProxyJump`）不生效，只写入备注。
- Windows 只提供 x64 构建。

## 校验

```powershell
Get-FileHash -Algorithm SHA256 .\TermDeck-Setup-2.4.0.exe
```

```bash
shasum -a 256 TermDeck-2.4.0-arm64.dmg
```

和附件里对应的 `SHA256SUMS-*.txt` 对一下即可。
