# TermDeck v1.4.0

## 新增

**快捷指令可以有自己的颜色**

给一条快捷指令挑个颜色，它会显示成**按钮下沿的一条色带** —— 一眼能把长得差不多的命令分开。

- 编辑器里八个常用色一格一个，右边还有系统取色器，想要什么色都行；也可以选「不设颜色」。
- 色带是画在按钮内下沿的三像素实色条，而不是给整个按钮染色：这个尺寸下三像素的实色最清楚，
  而整块染色要够显眼就会跟文字抢对比度。
- 颜色跟着快捷指令走，导出/重装都在。

**左侧的分组名合并成一个**

原来左边是一排分组标签，占掉整个左端。现在只有**一个按钮**：

- 默认显示「全部」；点开是一张勾选清单，每个分组一行、带数量，「全部」也在里面。
- **可以多选**：勾两个分组就同时显示这两组的内容，按钮上直接写出勾了哪些。
- 再点一下或按 `Esc`、点别处就收起；全都不勾等于「全部」。
- 分组之间搬东西改到右键菜单里（「移到 <分组>」），不再靠拖到标签上 —— 那排标签没了，
  而"未分组"始终是一个可选目标。

## 验证

完整闸门 `npm run verify`：41 套件全过。`smoke:snippet` 22 → **34 条**，新增 12 条直接对着这两件事：
颜色存得住、按钮上真的画出色带（比对实际计算出来的颜色）、没设颜色的按钮没有色带；分组只有一个控件、
默认「全部」、点开有每组一个勾选框、勾一个会收窄、勾第二个是**相加而不是替换**、全不勾恢复全部、
点外面会收起。
